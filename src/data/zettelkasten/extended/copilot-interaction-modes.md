**Copilot Interaction Modes** trace how [[GitHub Copilot]] evolved across three eras, from passive single-line ghost text to autonomous multi-surface execution in [[GitHub Platform Evolution]].

## Three Eras & Five Modes

| Era | Mode | Developer Interaction Model |
| --- | --- | --- |
| **1. The Co-pilot Era** | **LLM Code Completion** | Inline ghost-text and Next Edit suggestions as you type (zero AI credit cost on paid plans) |
| **1. The Co-pilot Era** | **Copilot Chat: Ask Mode** | Conversational Q&A, architecture explanations, and debugging answers grounded in repo context |
| **1. The Co-pilot Era** | **Copilot Chat: Edit Mode** | Controlled multi-file diffs applied directly to an explicit working set |
| **2. Rise of Agents** | **Agent Mode** | Autonomous planning, tool/MCP invocation, terminal test execution, and iterative self-correction in [[SDLC Stage 02 Code]] |
| **3. Beyond the IDE** | **Cross-Surface Agents** | Running outside the editor across [[Copilot Surfaces]], [[Agent HQ & Agent Teams]], and [[Partner Agents on One Subscription]] |
