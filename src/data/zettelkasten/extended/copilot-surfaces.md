**Copilot Surfaces** let developers invoke [[GitHub Copilot]] from whichever environment matches the task, sharing models from [[Copilot Multi-Model Catalog & BYOK]] and routing from [[Copilot Fusion]].

## Seven Supported Work Surfaces

| Surface | Primary Workflows |
| --- | --- |
| **IDEs** | Code with [[Copilot Interaction Modes]] in **VS Code**, **Visual Studio**, **JetBrains**, **Xcode**, **Eclipse**, or **Neovim** |
| **Copilot App** | Direct parallel agents, Projects, Computer Use, issue triage, and PR management ([[Innovate Pillar]], [[Agent HQ & Agent Teams]]) |
| **Terminal (CLI)** | Work directly from the shell with **Copilot CLI** in [[SDLC Stage 02 Code]] |
| **Cloud Agent & Code Review** | Delegate asynchronous Issue-to-PR implementation and automated PR reviews ([[SDLC Stage 03 Review]]) |
| **SDK** | Embed Copilot into custom internal applications via [[Copilot SDK]] |
| **Automation** | Turn recurring repository operations into [[Copilot Automations]] and Agentic Workflows in [[SDLC Stage 05 Operate]] |
| **Web & Mobile** | Chat, steer remote sessions, and kick off cloud tasks from `github.com` or GitHub Mobile |
