The **Trust Pillar** (`03 / Confidence`) is [[GitHub]]'s third Universe 2026 strategic pillar, ensuring enterprises retain full security visibility and supply-chain control as agents author a growing share of code ([[Octoverse & Agent Era Metrics]]).

## Universe 2026 Availability Map (Checked 2026-11-11)

| Release | Status | Security & Verification Highlights |
| --- | --- | --- |
| **AI Scan: Repositories** | `Preview` | LLM-assisted vulnerability detection across full repos (**AI Scan for Pull Requests** is `GA`) |
| **Agentic Autofix** | `GA` | Autonomous multi-file remediation for Code Scanning alerts (GA since `2026-10-15`) |
| **Reachability Analysis** | `Preview` | Prioritizes Dependabot alerts by checking real call-graph reachability for JS/TS on GHEC |
| **Package Firewall** | `Preview` | Blocks malicious or policy-violating `npm` dependencies at install time on GHEC (free during preview) |

Together with [[SDLC Stage 04 Test & Secure]], [[Copilot Proxy]], and [[Copilot Trust & IP Protection]], the Trust Pillar complements the [[Innovate Pillar]] and [[Scale Pillar]].
