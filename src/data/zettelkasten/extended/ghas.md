**GitHub Advanced Security (GHAS)** is GitHub's security suite built directly into [[GitHub]]. It scans repositories for the two things developers leak or introduce by accident: **credentials** and **vulnerable code**.

## Two Standalone Products

GHAS is sold as two unbundled products billed per active committer (anyone pushing to an enabled repository in the past 90 days; public repos get core features for free):

- [[Secret Protection]] ($19 / month / active committer): Keeps API keys, tokens, and passwords out of Git history.
- [[Code Security]] ($30 / month / active committer): Finds vulnerabilities in first-party source code and open-source dependencies ($49 / month when combined).

## Governance & Rollout at Scale

- [[Risk Assessments]]: Free pre-purchase inventory for Secret Risk and Code Security Risk across an organization.
- [[Security Configurations]]: Roll out and enforce settings across every organization and repository from a single policy.
- [[Security Overview]]: Track detection, remediation, coverage, risk, and [[Public Monitoring]] across organizations and enterprises.
