**SDLC Stage 05 Operate** closes the loop of the [[AI Developer Platform]], keeping repositories self-maintaining, observable, and continuously learning after code passes [[SDLC Stage 04 Test & Secure]].

## Operational & Intelligence Capabilities

| Capability | Category | Operational Role |
| --- | --- | --- |
| **Agentic Workflows** | Copilot | Markdown-defined repository agents running on GitHub Actions schedules and events (GA in the [[Scale Pillar]]) |
| **Copilot Memory & Dreaming** | Copilot | Persistent repository knowledge (`Memory` GA) and background context synthesis (`Dreaming` Public Preview) in the [[Innovate Pillar]] |
| **Copilot Metrics** | Copilot | Adoption, usage, code generation, and ROI telemetry across enterprise teams |
| **REST & GraphQL API** | Native Platform | Event webhooks and programmatic platform extensibility alongside [[Copilot SDK]] |
| **Packages & Registry** | Native Platform | Container and language package hosting integrated with Actions and repository permissions |
