**Personal Instructions** sit at the top of the [[Custom Instructions]] precedence hierarchy (`Personal > Repository > Organization`), shaping style, response language, and personal habits across every project you touch.

## Where Personal Instructions Live

| Surface | Configuration Path |
| --- | --- |
| **Copilot CLI** | `~/.copilot/copilot-instructions.md` |
| **VS Code** | User Settings (`github.copilot.chat.*.instructions`) |
| **GitHub.com** | Copilot Chat -> profile menu -> **Personal Instructions** |

## Scope Boundaries

- Applies only to your own sessions and is never committed to a repository (unlike [[Repository Instructions]]).
- Personal runs in [[Copilot Dreaming]] refine [[Copilot Memory]] only and **never modify** your personal instruction files.
