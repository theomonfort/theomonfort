**SDLC Stage 01 Plan** is the opening phase of the [[AI Developer Platform]], turning product ideas into structured specifications while preparing the context and tools that guide [[GitHub Copilot]].

## Native GitHub & Copilot Capabilities in Stage 01

| Capability | Category | Role in Planning |
| --- | --- | --- |
| **GitHub Projects** | Native Platform | Roadmaps, iterations, custom fields, and cross-repo tracking |
| **Issues & Discussions** | Native Platform | Structured work items, sub-issues, and architectural RFCs |
| **Plan Mode** | Copilot | Researching the codebase and aligning on an implementation blueprint before editing files |
| **MCP (Model Context Protocol)** | Copilot | Connecting external tools, schemas, and documentation into agent sessions |
| **Skills & Instructions** | Copilot | Reusable `SKILL.md` workflows and repository/org coding standards |
