**Claude Code on GitHub** integrates Anthropic's coding harness natively into [[Copilot in VS Code]] and [[Copilot Cloud Agent]] under [[Partner Agents]] (governed by [[Partner Agent Governance]]).

## VS Code vs Cloud Agent Execution

| Surface | Setup & Capabilities |
| --- | --- |
| **VS Code (Zero Extension Install)** | Pick `Claude` directly in [[VS Code Session Targets]] (`New Chat (+)`); runs the Claude Agent SDK with `Auto`, `Claude Opus 4.5/4.6/4.7`, `Claude Sonnet 4.5/4.6`, permission modes (`Edit automatically`, `Request approval`, `Plan`), and Claude slash commands |
| **Cloud Agent** | Select **Claude Agent SDK** for deep multi-step reasoning on Actions runners, protected by [[Cloud Agent Validation Tools]] and billed via Copilot AI credits |
