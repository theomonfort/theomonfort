**Copilot App Projects** (Public preview in the [[GitHub Copilot App]]) coordinate an ongoing goal across one, several, or zero repositories rather than a single isolated branch task.

## Project Surfaces & Loop

| Surface | Role |
| --- | --- |
| **Library** | Shared specifications, design files, spreadsheets, and deliverables generated across sessions |
| **Overview** | Live progress rollup across parallel child agent sessions |
| **Needs input** | Centralized inbox for human approval gates and clarifying decisions |
| **Project Automations** | Recurring scheduled tasks bound to the Project's shared context |

## When to Use Projects vs Sessions

- Start a direct repository session for one focused fix; create a Project when coordinating multi-repo delivery alongside [[Copilot Connectors]] and [[Native Office Canvases]].
