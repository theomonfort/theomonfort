**GitHub Discussions** is the built-in forum on [[GitHub]] for conversations with no single immediate task owner: architecture questions, early ideas, and team announcements.

## Core Capabilities

- **Q&A with Best Answer**: Mark the verified resolution so recurring engineering questions become searchable team knowledge.
- **Announcements**: Broadcast release notes, RFCs, and roadmap direction next to the code.
- **Polls**: Gather fast consensus from maintainers or product teams.
- **One-Click Issue Promotion**: Convert a settled discussion thread directly into [[Issues & Sub-issues]] when an idea is ready for execution.

## Real-World Reference

- GitHub runs its own product feedback and community Q&A on Discussions at `github.com/orgs/community/discussions`.
