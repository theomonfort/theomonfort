**OpenAI Codex on GitHub** brings OpenAI's coding harness into [[Copilot in VS Code]] and [[Copilot Cloud Agent]] as part of [[Partner Agents]] (enabled via [[Partner Agent Governance]]).

## VS Code vs Cloud Agent Execution

| Surface | Setup & Models |
| --- | --- |
| **VS Code** | Install the **OpenAI Codex** Marketplace extension and click **Sign in with Copilot**; supports OpenAI models (`Auto`, `GPT-5.2-Codex`, `GPT-5.3-Codex`, `GPT-5.4`, `GPT-5.4 nano`) routed through the Copilot API |
| **Cloud Agent** | Select **OpenAI Codex SDK** when delegating a task; runs on GitHub Actions runners with [[Cloud Agent Validation Tools]] and consolidated Copilot billing |
