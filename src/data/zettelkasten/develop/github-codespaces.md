**GitHub Codespaces** provides instant, cloud-hosted Docker development environments on [[GitHub]] (`1 session = 1 codespace`), giving every contributor and AI agent an identical, disposable sandbox.

## Connection Methods & Residency

- **Three Ways to Connect**: Open directly in the browser from `github.com`, attach remotely from [[Copilot in VS Code]], or SSH from the terminal with `gh codespace ssh` alongside [[Copilot CLI]].
- **Data Residency GA**: Generally available for GitHub Enterprise Cloud with data residency (`2026-04-01`), including regional availability in Japan (`2026-03-19`).
- **Safe AI Experimentation**: Standardizes environments via [[Dev Containers & Machine Sizes]], complements [[Local & Cloud Sandboxes]], and eliminates local setup drift.
