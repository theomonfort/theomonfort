**VS Code Chat Shortcuts & Commands** control prompts, context attachments, and customizations inside [[Copilot in VS Code]].

## Key Shortcuts & Controls

| Control | Behavior |
| --- | --- |
| **`⌃⌘I` (macOS) / `Ctrl+Alt+I` (Win/Linux)** | Opens the Chat view (updated shortcut as of `2026-11-06`) |
| **`/` Slash Commands** | `/plan`, `/chronicle`, `/env`, `/compact`, `/rename`, `/yolo`, `/create-canvas`, `/vscode-pet` |
| **`#` / Add Context (`+`)** | Attaches files, symbols, images, issues, or pull requests directly to the prompt |
| **`Chat: Open Customizations`** | Opens the visual manager for skills, custom agents, instructions, hooks, MCP servers, and plugins |

## Harness Note

- In the default Copilot harness, legacy `@` chat participants are deprecated and unsupported. Ask directly and attach `#` context or switch [[VS Code Session Targets]].
- Parallel multi-session shortcuts (`Alt+Enter`, `⌘1`-`⌘9`) also work inside the [[VS Code Agents Window]] and [[Git Worktree Isolation]].
