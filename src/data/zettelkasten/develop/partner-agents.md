**Partner Agents** let developers run third-party coding agent harnesses, specifically [[Claude Code on GitHub]] and [[OpenAI Codex on GitHub]], directly inside [[Copilot in VS Code]] and [[Copilot Cloud Agent]] on [[GitHub]].

## Harness Choice with Consolidated Billing

- **Harness != Chat Mode**: Switching to a Partner Agent delegates the task to that provider's agent loop and SDK rather than Copilot's native harness.
- **Single Subscription**: Billing, AI credits, rate limits, and [[Cloud Agent Validation Tools]] stay consolidated under your existing GitHub Copilot subscription with no separate vendor contract.
- **Opt-In Control**: Disabled by default until enabled through [[Partner Agent Governance]].
