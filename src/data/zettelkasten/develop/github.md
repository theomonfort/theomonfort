**GitHub** connects interactive IDE coding, terminal workflows, desktop orchestration, cloud sandboxes, and asynchronous background agents on one platform.

## Develop Surfaces & Engines on GitHub

- **VS Code Surfaces**: Side-by-side coding in [[Copilot in VS Code]] and cross-workspace multi-agent orchestration in the [[VS Code Agents Window]].
- **Terminal & Async Cloud**: Terminal-native coding and automation in [[Copilot CLI]], plus Issue-to-PR background execution on Actions runners with [[Copilot Cloud Agent]].
- **Goal-Oriented Desktop App**: Multi-repository Projects, Connectors, native Office canvases, and Computer Use in the [[GitHub Copilot App]].
- **Multi-Model & Partner Harnesses**: Consolidated Anthropic and OpenAI harnesses via [[Partner Agents]], effort-based model routing with [[Copilot Fusion]], and enterprise compliance filtering through [[Copilot Proxy]].
- **Cloud Environments & Context**: Reproducible cloud containers in [[GitHub Codespaces]] and curated multi-source knowledge rooms in [[Copilot Spaces]].
