**BYOK & On-Device Models** extend model selection in [[Copilot in VS Code]] and [[Copilot CLI]] beyond GitHub-hosted frontier families (`GPT / Codex`, `Claude`, `Gemini`, `Grok`, `MAI`, `Kimi`) and [[Copilot Fusion]].

## Three Custom & Local Options

1. **Bring Your Own Key (BYOK)**: Connect your own cloud LLM provider API keys directly inside supported Copilot clients (`2026-04-07` in CLI and VS Code).
2. **Copilot On-Device Models**: Run compact local models directly on supported developer hardware for low-latency offline assistance.
3. **Ollama via BYOK**: Point BYOK at a local Ollama endpoint to run open-weight models locally while keeping the familiar Copilot interface alongside [[Fusion Effort & Execution Patterns]].
