**Copilot in VS Code** pairs the side-by-side editor Chat view with the shared **Copilot** runtime harness (default since `2026-10-28`, replacing the legacy `Local` editor-only harness) on [[GitHub]].

## Default Copilot Harness Capabilities

- **Sandbox & Assisted Permissions**: Runs builds and tests inside file and network boundaries; routine calls auto-approve while sensitive actions request confirmation via [[Local & Cloud Sandboxes]].
- **Unified Runtime**: Shares skills, hooks, plugins, [[Copilot Connectors]], and [[Copilot Fusion]] with [[Copilot CLI]] and the [[GitHub Copilot App]].
- **Interactive Canvases**: Enable `chat.canvases.enabled` before starting a session to collaborate on task boards and diagrams alongside [[Native Office Canvases]].
- **Session Continuity**: Move seamlessly between editor Chat, the [[VS Code Agents Window]], [[VS Code Session Targets]], and [[Connected Cloud Continuity]] using [[VS Code Chat Shortcuts & Commands]].
