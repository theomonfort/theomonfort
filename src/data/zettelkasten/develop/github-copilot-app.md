The **GitHub Copilot App** (`macOS / Windows / Linux`, available across Copilot plans) is a goal-oriented desktop workspace on [[GitHub]] where developers coordinate parallel coding agents, external context, files, and pull requests in one place.

## Collaboration Modes & Isolation

| Session Mode | Developer Role |
| --- | --- |
| **Interactive** | Steer the agent step by step |
| **Plan** | Review and approve the structured plan before code changes begin |
| **Autopilot** | Delegate a bounded goal and review the finished diff or deliverables |
