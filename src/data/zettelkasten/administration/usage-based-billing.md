**Usage-Based Billing** (`UBB`) is [[GitHub]]'s metered consumption architecture across cloud compute (Actions, Codespaces, Packages) and, effective **June 1, 2026**, token-based AI usage across GitHub Copilot, cloud agent, Spark, and GitHub Advanced Security AI SKUs.

## GitHub AI Credits & Exchange Rate

- **Fixed Billing Unit**: AI usage is metered and reported in **GitHub AI credits**, pegged at **`1 AI credit = $0.01 USD`** (for example, a `$10` overage budget equals **`1,000 AI credits`**).
- **Unlimited Core Completions**: Inline **code completions** and **Next Edit suggestions** consume **zero AI credits** and remain unlimited on all paid [[GHE & Copilot Licenses]].
- **Data Residency Multiplier**: Enabling strict in-region model routing on [[Copilot with Data Residency]] adds **`+10%`** AI credit consumption.

## Token Formula & Processing Categories

Every interactive Chat, CLI, code review, or cloud agent turn charges credits according to model-specific token pricing rates (replacing the legacy [[Premium Request Model]]):

`Billable tokens = Input tokens + Output tokens + Cached tokens`

| Token Category | What It Represents | Cost & Scaling Driver |
| --- | --- | --- |
| **Input tokens** | User prompt plus newly attached files, diffs, and tool outputs | Grows with large files, broad codebase searches, and long sessions |
| **Output tokens** | Reasoning and code/text generated by the AI model | Highest per-token compute rate across frontier models |
| **Cached tokens** | Reused prompt/conversation context from prior turns | Discounted rate that accelerates multi-turn agentic loops |

## Pooled Included Credits vs Metered Overage

License-included credits aggregate into the enterprise [[Shared AI Credit Pool]]; once exhausted, additional token consumption bills as USD overage governed by [[Cost Centers]], [[Budgets & Spending Limits]], and [[Budget Hierarchy]].
