**Code Security** is one of the two products in [[GHAS]] ($30 / month per active committer, paired alongside [[Secret Protection]]). It secures both the code your team writes and the open-source packages your project pulls in.

## Core Capabilities

- [[Code Scanning]] (SAST): Static analysis powered by [[CodeQL]], [[AI Scan]], and [[Third-Party SARIF]] to catch exploitable flaws before merge, paired with [[Copilot Autofix]] and [[Agentic Autofix]].
- [[Dependabot]] (SCA): Supply-chain monitoring and automated dependency remediation built on the [[Dependency Graph]], including [[Dependency Review]], [[Open Source License Compliance]], [[Reachability Analysis]], and [[Package Firewall]].

## At-Scale Management

- [[Security Campaigns]]: Slice large alert backlogs into finishable sprints with an owner and due date.
- [[Risk Assessments]]: Run a free Code Security Risk Assessment on up to 20 active repositories before licensing.
- [[Security Overview]]: Monitor vulnerability risk and scan coverage across the organization.
