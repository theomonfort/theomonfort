**GitHub Projects** is the live planning surface on [[GitHub]] providing spreadsheet, board, and timeline views directly over [[Issues & Sub-issues]] and Pull Requests.

## Key Capabilities

- **Multiple Views**: Switch seamlessly between **Table** (spreadsheet), **Board** (Kanban), and **Roadmap** (timeline) layouts over the same underlying items.
- **Typed Fields**: Combine project-scoped custom fields (iteration, estimate, status) with organization-wide [[Issue Fields]].
- **Built-in Workflows**: Auto-update item status when issues are assigned, PRs open, or `Closes #123` merges via [[Issue Templates & PR Linking]].
- **Progress Insights**: Chart velocity, burnup, and status distribution without exporting data (`github.com/orgs/vitejs/projects/1`).
