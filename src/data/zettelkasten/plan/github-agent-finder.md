**GitHub Agent Finder** (`github.com/agentfinder`) is a cross-ecosystem discovery service that searches simultaneously across [[MCP Servers]], tools, [[Agent Skills]], and [[Custom Agents]] for a given engineering task.

## Installation & Usage

```bash
gh skills install ards-project/connectors skills/github-copilot
```

- Installed via [[Skill Registries & CLI]] from `ards-project/connectors` (`skills/github-copilot/SKILL.md`).
- Run `/agentfinder <what you want>` (for example databases, email, cloud deploy, or monitoring) to list matching installable integrations before configuring them.
