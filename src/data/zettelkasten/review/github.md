**GitHub** is the collaborative platform where every human, bot, and coding agent change passes through structured code review, automated checks, and branch governance before landing on `main`.

## Code Review & Merge Pillars on GitHub

- **Branching & Pull Request Lifecycle**: Short-lived feature branches under [[GitHub Flow]] converge in [[Pull Requests]] (~90M merges per month in 2026), pairing diff discussion, automated CI, and merge strategies in one workspace.
- **Human Ownership & Review Routing**: Path-based stewardship in [[CODEOWNERS]] routes changes to the right domain maintainers and teams before merge.
- **Stacking & Autonomous Landing**: Dependent layered branches in [[Stacked Pull Requests]], serialized CI batching in [[Merge Queue]], and last-mile blocker resolution via [[Agent Merge]].
- **AI-Powered Review**: Agentic context gathering, inline suggestions, and effort tiers in [[Copilot Code Review]].
- **Branch Governance & PR Gates**: Top-down repository, organization, and enterprise enforcement via [[PR Rulesets]], backed by [[Code Scanning PR Merge Protection]] and [[Code Quality PR Findings]].
