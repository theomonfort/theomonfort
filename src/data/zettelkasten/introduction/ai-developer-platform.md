The **AI Developer Platform** integrates native [[GitHub]] collaboration/DevSecOps tooling with [[GitHub Copilot]] agents across all five stages of the software development lifecycle (SDLC), rather than isolating AI inside code completion alone.

## Five End-to-End SDLC Stages

1. **01 Plan** ([[SDLC Stage 01 Plan]]): Scope work in Projects, Issues, and Discussions while configuring Plan Mode, MCP servers, Agent Skills, and Custom Instructions.
2. **02 Code** ([[SDLC Stage 02 Code]]): Implement features synchronously or asynchronously across Copilot Chat, Cloud Agent, Copilot CLI, Copilot App, and Codespaces.
3. **03 Review** ([[SDLC Stage 03 Review]]): Inspect changes through Pull Requests, Copilot Code Review, Playwright browser checks, and Rubber Duck review.
4. **04 Test & Secure** ([[SDLC Stage 04 Test & Secure]]): Enforce CI and DevSecOps gates via Actions, Autofix, Code Quality, Code Scanning, and Secret Protection.
5. **05 Operate** ([[SDLC Stage 05 Operate]]): Run continuous repository automation with Agentic Workflows, Copilot Memory, Copilot Metrics, REST/GraphQL APIs, and Packages.

## Native Platform + Copilot Synergy

Every stage combines deterministic platform primitives (`Projects`, `Codespaces`, `Pull Requests`, `Actions`, `APIs`) with agentic intelligence orchestrated across [[Copilot Surfaces]] and governed under the [[Innovate Pillar]], [[Scale Pillar]], and [[Trust Pillar]].
