**Octoverse & Agent Era Metrics** capture the structural shift on [[GitHub]] between October 2025 and September 2026: **the first draft of software has changed**, with autonomous agents initiating a massive share of new code.

## Agent-Started Pull Request Surge (September 2026)

- **>40%** of all pull requests on GitHub now start with an agent.
- **110M** agent-started pull requests opened in **September 2026 alone**.
- **~6x** growth in agent-started PR volume in six months (March to September 2026), driven by [[GitHub Copilot]] and [[Agent HQ & Agent Teams]].

## Annual & Monthly Platform Volume (2026 vs 2025)

| Metric | 2026 Annual Total (YoY Growth) | 2026 Monthly Peak (Universe Keynote) |
| --- | --- | --- |
| **Merged PRs** | **1.3B** (`2.4x` vs 2025) | **220M** merged PRs / month |
| **Commits** | **34.3B** (`2.7x` vs 2025) | **7.38B** commits / month |

## Ecosystem & Bottleneck Implication

- **Global & Regional Reach**: **225M+** total developers worldwide (`>1/sec` joining, **2.5B** public contributions), including **7.15M developers in Japan** (`#5` globally as of September 2026).
- **>90% YoY Growth** in both AI code review ([[SDLC Stage 03 Review]]) and GitHub Advanced Security ([[SDLC Stage 04 Test & Secure]]).
- **Core Implication**: As agents write more code on [[Git Infrastructure & Scale]], human review, automated verification, and governance under the [[Trust Pillar]] become the primary engineering bottleneck.
