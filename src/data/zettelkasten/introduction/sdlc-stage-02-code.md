**SDLC Stage 02 Code** is the implementation phase of the [[AI Developer Platform]], pairing cloud-hosted development containers with synchronous and asynchronous [[Copilot Surfaces]].

## Five Core Coding Environments

- **Copilot Chat** (`Copilot`): Interactive Ask, Edit, and Agent Mode inside VS Code, Visual Studio, JetBrains, Xcode, Eclipse, and Neovim ([[Copilot Interaction Modes]]).
- **Cloud Agent** (`Copilot`): Asynchronous background agent that turns assigned Issues from [[SDLC Stage 01 Plan]] into draft pull requests, alongside [[Partner Agents on One Subscription]].
- **Copilot CLI** (`Copilot`): Terminal-native agentic coding, shell automation, and multi-subagent `/fleet` execution.
- **Copilot App** (`Copilot`): Desktop workspace for steering parallel sessions, Projects, [[Copilot Automations]], and Computer Use under the [[Innovate Pillar]].
- **GitHub Codespaces** (`Native Platform`): Zero-setup, reproducible cloud containers preloaded with dependencies and extensions.

All changes converge as branches and draft pull requests entering [[SDLC Stage 03 Review]], routed dynamically by [[Copilot Fusion]].
