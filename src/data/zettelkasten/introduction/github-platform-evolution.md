**GitHub Platform Evolution** traces how [[GitHub]] progressed from collaborative version control to coordinated multi-agent software delivery.

## Six Platform Milestones (2008 to 2026)

| Year | Milestone | Core Shift |
| --- | --- | --- |
| **2008** | **Pull Requests** | Made asynchronous code collaboration and review the default |
| **2012** | **GitHub Enterprise** | Brought identity, compliance, and governance to team development |
| **2019** | **Actions & GHAS** | Automated CI/CD delivery and native code/secret security in [[SDLC Stage 04 Test & Secure]] |
| **2021** | **GitHub Copilot** | Introduced [[GitHub Copilot]] as the first mainstream AI pair programmer |
| **2025** | **Agent HQ** | Enabled delegating tasks and tracking asynchronous coding sessions |
| **2026** | **Projects & Agent Groups** | Unified one goal, shared context, and parallel specialist agents in [[Agent HQ & Agent Teams]] |

## Four Eras of Developer Work

- **Through 2020 (Files / execution)**: Manual file editing and script execution.
- **2021 to 2024 (Suggestions / diffs)**: Inline completions and chat diffs inside [[Copilot Interaction Modes]].
- **2025 (Tasks / sessions)**: Single-task delegation to cloud and CLI sessions, fueling the surge in [[Octoverse & Agent Era Metrics]].
- **2026 (Projects / agent groups)**: Coordinating multiple agents across repositories and GUIs on top of [[AI Developer Platform]].
