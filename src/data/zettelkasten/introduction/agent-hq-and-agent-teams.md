**Agent HQ & Agent Teams** represent the 2025 to 2026 culmination of [[GitHub Platform Evolution]] on [[GitHub]]: shifting from single-session task delegation (`Agent HQ`) to persistent **Projects and Agent Groups** that coordinate multiple agents and GUI tools toward a shared goal.

## Goal-Oriented Agent Team Architecture

1. **You (Human Lead)**: Set the goal, choose priorities, approve sensitive tool access, and judge final results.
2. **Project (Shared Context + Memory)**: Holds durable context, artifacts, and repository memory across sessions in the Copilot App ([[Innovate Pillar]], [[Copilot Surfaces]]).
3. **Coordinating Agent**: Breaks the objective down and orchestrates specialist sub-roles in parallel:
   - **Implement** (code & tests in [[SDLC Stage 02 Code]])
   - **Review** (verification & critique in [[SDLC Stage 03 Review]])
   - **Research** (cross-repo & web investigation in [[SDLC Stage 01 Plan]])
4. **Tools & Apps (`Browser` + `Computer Use`)**: Agents interact with live browsers and desktop applications with explicit permission gates, returning progress, artifacts, and decisions to the developer alongside [[Copilot Automations]] and [[Partner Agents on One Subscription]].
