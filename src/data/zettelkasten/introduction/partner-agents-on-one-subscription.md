**Partner Agents on One Subscription** lets developers run third-party coding agent harnesses (**Anthropic Claude** and **OpenAI Codex**) alongside [[GitHub Copilot]] under a single enterprise contract and unified AI credit pool.

## Two Execution Environments, Three Harnesses Each

| Environment | Available Agent Harnesses | Workflow Fit |
| --- | --- | --- |
| **IDE Agents** (Interactive) | **Copilot**, **Codex**, **Claude** | Synchronous local exploration, refactoring, and pair coding across [[Copilot Surfaces]] |
| **Cloud Agents** (Async Coding) | **Copilot Cloud Agent**, **Claude Coding Agent**, **Codex Coding Agent** | Asynchronous Issue-to-PR delegation and parallel tasks in [[SDLC Stage 02 Code]] and [[Agent HQ & Agent Teams]] |

## Unified Billing & Governance

- **Single Subscription**: All partner agent runs draw directly from **GitHub Copilot AI credits**, eliminating separate procurement contracts while preserving model diversity alongside [[Copilot Multi-Model Catalog & BYOK]].
