---
title: "レビューの推論レベル"
---

**レビューの推論レベル**は、**Copilot Pro、Pro+、Max、Business、Enterprise** の各プランで、作者と管理者が [[Copilot Code Review]] ごとの推論の深さ、待ち時間、AI クレジットのコストを調整する機能です。

## 推論レベルと推定コスト（2026年11月11日確認）

| 推論レベル | 構成と深さ | レビューあたりの推定コスト（USD） | 対象の作業 |
| --- | --- | --- | --- |
| **Lite** | 複数の観点を持つ高速エージェント群の結果を、1つの簡潔なレビューに統合 | **`$0.05 to $1.00`** | 日常的な差分、設定更新、[[Draft Pull Requests|ドラフトプルリクエスト]]での素早い反復 |
| **Balanced** *（既定）* | 高度な推論モデルが [[Agentic Review Tool-Calling|エージェント型レビューのツール呼び出し]]でファイル横断のロジック、境界ケース、セキュリティ上重要なコードを確認 | **`$0.25 to $5.00`** | 日々の機能追加とバグ修正の [[Pull Requests|プルリクエスト]] |
| **Max** *（パブリックプレビュー、2026年10月28日）* | **異なるモデルプロバイダー**の複数の独立した高推論エージェントが指摘を相互確認、整合、検証 | **`$1.50 to $25.00`** | 高リスクな認証、課金、暗号、スキーマ移行、重要インフラの変更 |

## 選択方法と Enterprise の推論レベル上限

- **PR ごとの上書き**：ポリシーで許可されていれば、各 PR の **Reviewers** メニューから `Lite`、`Balanced`、`Max` を選択できます。
- **管理者の既定値と上限**：Enterprise、Organization、Repository の管理者は既定の推論レベルと**最大推論レベル**を設定します（`Max` は管理者の上限で許可されている場合のみ選択可能）。
- **課金上の注意**：価格の幅はプロンプトの大きさと [[Review Custom Instructions|レビュー用カスタム指示]]の長さを反映します。[[Review Runner & Quota Governance|レビューランナーと利用枠のガバナンス]]に基づく GitHub Actions ランナーの分数は別途課金され、`Max` は [[Copilot Review Approvals|Copilot レビューの承認]]とは独立しています。
