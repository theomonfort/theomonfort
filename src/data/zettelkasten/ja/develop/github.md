title: "GitHub"
---

**GitHub** は、対話型 IDE コーディング、ターミナルのワークフロー、デスクトップでのオーケストレーション、クラウドサンドボックス、非同期のバックグラウンドエージェントを1つのプラットフォームにつなぎます。

## GitHub の開発環境とエンジン

- **VS Code の利用環境**: [[Copilot in VS Code]] での並走型コーディングと、[[VS Code Agents Window]] でのワークスペース横断の複数エージェント調整。
- **ターミナルと非同期クラウド**: [[Copilot CLI]] のターミナルネイティブなコーディングと自動化、[[Copilot Cloud Agent]] による Actions ランナー上での Issue から PR までのバックグラウンド実行。
- **目標指向のデスクトップアプリ**: [[GitHub Copilot App]] の複数リポジトリにまたがる Projects、Connectors、Office ネイティブのキャンバス、Computer Use。
- **複数モデルとパートナーの実行基盤**: [[Partner Agents]] による Anthropic / OpenAI の実行基盤の統合、[[Copilot Fusion]] の Effort に基づくモデルルーティング、[[Copilot Proxy]] によるエンタープライズのコンプライアンスに対応したフィルタリング。
- **クラウド環境とコンテキスト**: [[GitHub Codespaces]] の再現可能なクラウドコンテナーと、[[Copilot Spaces]] の複数ソースから厳選した知識をまとめる空間。
