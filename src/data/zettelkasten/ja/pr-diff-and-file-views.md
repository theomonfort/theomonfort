---
title: "PR の差分とファイル表示"
---

**PR の差分とファイル表示**は、[[Pull Requests|プルリクエスト]]の **Files changed** タブを支えます。構造化されたナビゲーション、差分範囲の段階的な絞り込み、複数コミットにわたるレビュー進捗の保持を提供します。

## 差分を確認する操作

| 機能 | `Files changed` 内の場所 | レビュアーへの利点 |
| --- | --- | --- |
| **統合差分と分割差分** | 差分設定の歯車（`Unified` / `Split`） | 1列のインライン差分、または変更前後を横に並べた列で比較 |
| **空白を非表示** | 差分設定 → `Hide whitespace`（`?w=1`） | リファクタリング時にインデントのみの変更を除外し、ロジックの変更を目立たせる |
| **ファイルツリーとフィルター** | 左側のファイルツリーサイドバー + `Filter changed files` | 拡張子、`.github/CODEOWNERS` の所有者（[[CODEOWNERS]]）、未確認ファイルで絞り込む |
| **ファイルごとの `Viewed` チェックボックス** | 各ファイルカードの右上ヘッダー | 確認済みファイルを折りたたみ、`X / Y files viewed` で進捗を記録。後続のプッシュでそのファイルが変更されると自動リセット |
| **コミットと範囲の選択** | `Changes from all commits` ドロップダウン | `Changes since your last review` に差分を限定、または作者が変更を原子的なコミットに分けている場合はコミットごとに確認 |
| **リッチな差分表示** | `.md`、`.svg`、画像のレンダリング済みファイル表示ボタン | 生のソースとともに、レンダリングされた Markdown の表、図、画像の視覚的な差分をプレビュー |

## 差分とフィードバックの連携

- 差分内の行番号をクリックまたはドラッグすると、[[Inline Review Comments & Threads|インラインレビューコメントとスレッド]]を開くか、選択範囲に直接コミット可能な [[Suggested Changes|変更提案]]を挿入できます。
