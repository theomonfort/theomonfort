---
title: "Octoverse とエージェント時代の指標"
---

**Octoverse とエージェント時代の指標**は、2025年10月から2026年9月までの [[GitHub]] における構造的な変化を捉えます。**ソフトウェアの最初の下書きが変わり**、新しいコードの大きな割合を自律エージェントが書き始めています。

## エージェント起点の PR の急増（2026年9月）

- GitHub 上の全プルリクエストの**40%超**が、現在はエージェントから始まっています。
- **2026年9月だけで1億1,000万件**のエージェント起点の PR が作成されました。
- [[GitHub Copilot]] と [[Agent HQ & Agent Teams]] を背景に、エージェント起点の PR 数は6か月（2026年3〜9月）で**約6倍**に増えました。

## プラットフォームの年間件数と月間件数（2026年と2025年の比較）

| 指標 | 2026年の年間合計（前年比） | 2026年の月間ピーク（Universe 基調講演） |
| --- | --- | --- |
| **マージ済み PR** | **13億件**（2025年比 `2.4x`） | 月間 **2億2,000万件**のマージ済み PR |
| **コミット** | **343億件**（2025年比 `2.7x`） | 月間 **73億8,000万件**のコミット |
| **プッシュ** | **179億件**（2025年比 `2.7x`） | 数十億件規模のプッシュ頻度が継続 |
| **Actions ジョブ** | **454億件**（2025年比 `3.2x`） | 月間 **3,030万件**の新規リポジトリ |

## エコシステムとボトルネックへの示唆

- **世界と地域への広がり**: 世界の開発者は **2億2,500万人超**（参加速度は `>1/sec`、公開コントリビューションは **25億件**）。日本には **715万人の開発者**がいます（2026年9月時点で世界 `#5`）。
- AI コードレビュー（[[SDLC Stage 03 Review]]）と GitHub Advanced Security（[[SDLC Stage 04 Test & Secure]]）は、どちらも**前年比90%超の成長**。
- **中心的な示唆**: [[Git Infrastructure & Scale]] 上でエージェントが書くコードが増えるほど、人間のレビュー、自動検証、[[Trust Pillar]] に基づくガバナンスが、エンジニアリングの主要なボトルネックになります。
