---
title: "Copilot の利用環境"
---

**Copilot の利用環境**により、開発者はタスクに合った場所から [[GitHub Copilot]] を呼び出せます。[[Copilot Multi-Model Catalog & BYOK]] のモデルと [[Copilot Fusion]] のルーティングを共有します。

## 対応する 7 つの作業環境

| 環境 | 主なワークフロー |
| --- | --- |
| **IDE** | [[Copilot Interaction Modes]] を使い、**VS Code**、**Visual Studio**、**JetBrains**、**Xcode**、**Eclipse**、**Neovim** でコーディング |
| **Copilot App** | 並列エージェント、Projects、Computer Use、Issue トリアージ、PR 管理を指揮（[[Innovate Pillar]]、[[Agent HQ & Agent Teams]]） |
| **ターミナル（CLI）** | [[SDLC Stage 02 Code]] で **Copilot CLI** を使い、シェルから直接作業 |
| **Cloud Agent と Code Review** | Issue から PR への非同期実装と PR の自動レビューを委任（[[SDLC Stage 03 Review]]） |
| **SDK** | [[Copilot SDK]] で独自の社内アプリへ Copilot を組み込み |
| **自動化** | 定常的なリポジトリ運用を、[[Copilot Automations]] と [[SDLC Stage 05 Operate]] の Agentic Workflows に変換 |
| **Web と Mobile** | `github.com` または GitHub Mobile からチャット、リモートセッションの指示、クラウドタスクの開始 |

## 各環境の詳細
