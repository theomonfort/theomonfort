**Copilot の操作モード**は、[[GitHub Copilot]] が、受動的な 1 行のゴーストテキストから、複数の環境にまたがる自律実行へと 3 つの時代を経て進化した流れを示します（[[GitHub Platform Evolution]]）。

## 3 つの時代と 5 つのモード

| 時代 | モード | 開発者とのやり取り |
| --- | --- | --- |
| **1. 副操縦士の時代** | **LLM コード補完** | 入力中のインラインのゴーストテキストと Next Edit 提案（有料プランでは AI クレジット消費ゼロ） |
| **1. 副操縦士の時代** | **Copilot Chat: Ask モード** | リポジトリのコンテキストに基づく対話型 Q&A、アーキテクチャの説明、デバッグの回答 |
| **1. 副操縦士の時代** | **Copilot Chat: Edit モード** | 明示的な作業対象に直接適用する、制御された複数ファイルの差分 |
| **2. エージェントの台頭** | **Agent モード** | [[SDLC Stage 02 Code]] での自律的な計画、ツール / MCP 呼び出し、ターミナルでのテスト実行、反復的な自己修正 |
| **3. IDE の外へ** | **環境横断のエージェント** | [[Copilot Surfaces]]、[[Agent HQ & Agent Teams]]、[[Partner Agents on One Subscription]] を通じ、エディターの外で実行 |
