**Agent HQ とエージェントチーム**は、2025～2026 年の [[GitHub Platform Evolution]] が [[GitHub]] 上で到達した姿です。単一セッションへのタスク委任（`Agent HQ`）から、複数のエージェントと GUI ツールが共通の目標に向けて連携する、永続的な **Projects と Agent Groups** へ移行します。

## 目標指向のエージェントチーム構成

1. **あなた（人間のリーダー）**: 目標と優先順位を決め、機密性の高いツールへのアクセスを承認し、最終結果を評価します。
2. **Project（共有コンテキストとメモリ）**: Copilot App のセッションをまたいで、永続的なコンテキスト、成果物、リポジトリのメモリを保持します（[[Innovate Pillar]]、[[Copilot Surfaces]]）。
3. **調整役エージェント**: 目標を分解し、専門の役割を並列に調整します。
   - **実装**（[[SDLC Stage 02 Code]] でコードとテストを作成）
   - **レビュー**（[[SDLC Stage 03 Review]] で検証と批評）
   - **調査**（[[SDLC Stage 01 Plan]] でリポジトリ横断と Web の調査）
4. **ツールとアプリ（`Browser` + `Computer Use`）**: 明示的な権限確認を経て、エージェントが実際のブラウザーやデスクトップアプリを操作します。[[Copilot Automations]] や [[Partner Agents on One Subscription]] と連携し、進捗、成果物、判断事項を開発者へ返します。
