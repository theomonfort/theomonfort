**SDLC ステージ01：計画**は、[[AI Developer Platform|AI 開発者プラットフォーム]]の最初のフェーズです。製品のアイデアを構造化された仕様に変えながら、[[GitHub Copilot]] を導くコンテキストとツールを準備します。

## ステージ01の GitHub 標準機能と Copilot 機能

| 機能 | 分類 | 計画での役割 |
| --- | --- | --- |
| **GitHub Projects** | プラットフォーム標準 | ロードマップ、イテレーション、カスタムフィールド、リポジトリ横断の追跡 |
| **Issues と Discussions** | プラットフォーム標準 | 構造化された作業項目、サブ Issue、アーキテクチャの RFC |
| **計画モード** | Copilot | ファイルを編集する前にコードベースを調査し、実装の設計図について合意 |
| **MCP（Model Context Protocol）** | Copilot | 外部ツール、スキーマ、ドキュメントをエージェントセッションに接続 |
| **スキルと指示** | Copilot | 再利用可能な `SKILL.md` ワークフローと、リポジトリ / Organization のコーディング標準 |

## 次の段階への引き継ぎ

範囲が明確な Issue とカスタマイズ済みのエージェント基盤は、[[SDLC Stage 02 Code|SDLC ステージ02：コード]]での実装と [[Agent HQ & Agent Teams|Agent HQ とエージェントチーム]]でのマルチエージェント連携に直接つながります。
