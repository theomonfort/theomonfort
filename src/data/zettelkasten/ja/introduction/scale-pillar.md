---
title: "Scale の柱"
---

**Scale の柱**（`02 / Reach`）は、[[GitHub]] の Universe 2026 における第2の戦略的な柱です。強靭なインフラと一元的なガバナンスのもとで、企業のすべてのチームに AI ワークフローを届けることを目指します。

## Universe 2026 の提供状況（2026年11月11日確認）

| リリース | 状態 | 拡張性とガバナンスの要点 |
| --- | --- | --- |
| **Enterprise + Copilot** | `Sales` | 営業経由で、[[GitHub Copilot]] へのアクセスを組み合わせた GitHub Enterprise Cloud を提供（セルフサービスは未提供） |
| **Git インフラ** | `Underway` | 2027年初頭を目標とする基盤 Git のスケールアップと Azure への移行（[[Git Infrastructure & Scale|Git インフラと拡張性]]） |
| **Agentic Workflows** | `GA` | GitHub Actions 内で安全に実行する自然言語のリポジトリエージェント（[[SDLC Stage 05 Operate|SDLC ステージ05：運用]]） |
| **Actions ロックファイル** | `GA` | GitHub Actions ワークフローの依存関係を固定する暗号学的なロックファイル（[[SDLC Stage 04 Test & Secure|SDLC ステージ04：テストとセキュリティ]]） |
| **Copilot ガバナンス** | `GA` | リポジトリのプラグイン既定値と、Enterprise の一元的なプラグイン制御 |

[[Innovate Pillar|Innovate の柱]]、[[Trust Pillar|Trust の柱]]と連携する Scale は、運用やポリシーの逸脱を招かずに組織がエージェントを展開できるようにします。
