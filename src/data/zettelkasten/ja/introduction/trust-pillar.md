title: "Trust の柱"
---

**Trust の柱**（`03 / Confidence`）は、[[GitHub]] の Universe 2026 における第3の戦略的な柱です。エージェントが作成するコードの割合が増えても、企業がセキュリティ全体の可視性とサプライチェーンの制御を維持できるようにします（[[Octoverse & Agent Era Metrics|Octoverse とエージェント時代の指標]]）。

## Universe 2026 の提供状況（2026年11月11日確認）

| リリース | 状態 | セキュリティと検証の要点 |
| --- | --- | --- |
| **AI Scan：リポジトリ** | `Preview` | LLM を活用してリポジトリ全体の脆弱性を検出（**AI Scan for Pull Requests** は `GA`） |
| **Agentic Autofix** | `GA` | Code Scanning アラートに対し、複数ファイルを自律的に修復（`2026-10-15` から一般提供） |
| **到達可能性分析** | `Preview` | GHEC の JS / TS で実際の呼び出しグラフの到達可能性を確認し、Dependabot アラートを優先順位付け |
| **Package Firewall** | `Preview` | GHEC で悪意ある、またはポリシー違反の `npm` 依存関係をインストール時にブロック（プレビュー期間は無料） |

Trust の柱は [[SDLC Stage 04 Test & Secure|SDLC ステージ04：テストとセキュリティ]]、[[Copilot Proxy]]、[[Copilot Trust & IP Protection|Copilot の信頼性と知的財産の保護]]とともに、[[Innovate Pillar|Innovate の柱]]と [[Scale Pillar|Scale の柱]]を補完します。
