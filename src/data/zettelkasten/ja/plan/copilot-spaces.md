---
title: "Copilot Spaces"
---

**Copilot Spaces**（Spaces API は `2026-05-18` に GA）は、[[GitHub]] 上で、機能開発の開始、アーキテクチャの Q&A、オンボーディング、チームの定常ワークフローに使う、整理されたコンテキストの共有空間を作成します。

## ソースと情報取得の仕組み

| ソースの種類 | Copilot の処理方法 | 適した用途 |
| --- | --- | --- |
| **Space の指示** | Space 内の役割、期待する回答、境界を定義 | 一般論や根拠のない回答の防止 |
| **リポジトリ** | 必要な部分をオンデマンドで検索、取得（リポジトリ全体を一括投入しない） | 大規模コードベース全体のアーキテクチャ把握 |
| **ファイル / フォルダー / Issue / PR** | 優先してより一貫して参照し、Git と同期 | 仕様、API 契約、主要な実装 |
| **アップロードと自由形式メモ** | アップロードしたスナップショット（ドキュメント、画像、スプレッドシート）と会議 / 設計メモを使用 | 外部コンテキストと組織内の暗黙知に関する FAQ |

## 所有権と IDE エージェント統合

- **Organization**（`Admin / Editor / Viewer / No access`）または**個人**が所有します。共有しても、元の GitHub リポジトリの権限は迂回しません。
- リモートの [[GitHub MCP Server]] を通じて、IDE Agent モード内から直接アクセスできます（`"X-MCP-Toolsets": "default,copilot_spaces"` → `list_copilot_spaces` と `get_copilot_space`）。
