**GitHub** は、チームの計画、リポジトリのコンテキスト、Copilot のカスタマイズを同じ場所にまとめる中心的なプラットフォームです。

## GitHub の計画管理と Copilot の基本機能

- **計画と追跡**: [[GitHub Discussions]] の開かれたチーム Q&A、[[Issues & Sub-issues]] でのタスク分解と `Assign to Copilot`、[[GitHub Projects]] の Table / Board / Roadmap による追跡。
- **Copilot のカスタマイズ**: [[Custom Instructions]] の常設ルール、[[Agent Skills]] のタスクに応じて起動するワークフロー、[[Agent Plugins]] の持ち運び可能なバンドル、[[Custom Agents]] の専門的な役割、[[Hooks]] のライフサイクルスクリプト。
- **ツールと厳選したコンテキスト**: [[MCP Servers]]、[[GitHub MCP Server]]、[[Copilot Connectors]] のリアルタイム連携と、[[Copilot Spaces]]、[[Copilot Memory]]、[[Copilot Dreaming]] の組み合わせ。
- **エンタープライズガバナンス**: [[Copilot Managed Settings]] によるクライアントポリシーの一元管理、サンドボックス化、組織 / エンタープライズのエージェント配布。
