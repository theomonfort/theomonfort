---
title: "パッケージファイアウォール"
---

[[Dependabot Alerts & Updates]] と [[Dependency Review]] が Git コミットや PR を検査するのに対し、**パッケージファイアウォール**（[[Dependabot]] のパブリックプレビュー、[[Code Security]] に含まれる）は、開発者のノート PC、コーディングエージェントのサンドボックス、CI ランナーにおける**インストール処理そのもの**（`npm install`）を保護します。

## ダウンロードに関する3つのポリシー

1. **既知の脆弱性とマルウェア**: 指定した重大度のしきい値で、CVE または悪意あるパッケージのアドバイザリに一致するダウンロードをブロックします。
2. **最低バージョン経過日数（クールダウン）**: 公開直後のパッケージバージョン（例: 公開から `< 7 days`）を保留し、侵害されたメンテナーによるリリースをオープンソースコミュニティが検証する時間を確保します。
3. **来歴とライフサイクルスクリプトの後退**: **SLSA ビルドアテステーション**が突然なくなったり、予期しない `preinstall` / `postinstall` スクリプトが追加されたりしたバージョンを指摘します。

GitHub のレジストリプロキシを直接利用するか、JFrog Artifactory の前段につないで動作させます。**Enforce** と **Audit** モードがあります。
