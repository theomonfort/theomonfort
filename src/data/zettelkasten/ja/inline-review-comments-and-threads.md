---
title: "インラインレビューコメントとスレッド"
---

**インラインレビューコメントとスレッド**は、[[PR Diff & File Views|PR の差分とファイルビュー]]で、[[Pull Requests|プルリクエスト]]の1行または複数行の範囲へ技術的な議論を直接結び付けます。

## コメントの位置とスレッドのライフサイクル

- **1行 / 複数行の選択**: 差分行の `+` をクリックするか、ガターの複数行番号をドラッグすると、議論する正確なコードブロックにフィードバックを付けられます。コミット可能な [[Suggested Changes|変更の提案]]も含められます。
- **古い差分の追跡**: 後続コミットがコメント対象行を変更すると、GitHub は **Conversation** タブに `Outdated` バッジ付きでスレッドを残し、元の差分スナップショットを展開する切り替えも保持します。
- **解決と再オープン**: 修正が入ったら作成者やレビュアーが **Resolve conversation** をクリックし、完全な監査履歴を残したままスレッドを折りたたみます。

## スレッド解決の必須化

- [[Required Pull Request Reviews|必須のプルリクエストレビュー]]で **Require conversation resolution before merging** を有効にすると、インラインスレッドが1つでも未解決なら [[Auto-Merge|自動マージ]]と手動マージをブロックします。人間のレビュアー、[[Copilot Code Review]]、`Evaluate` モードのルールセットチェックからのスレッドも対象です。
- Copilot Code Review は、新たにプッシュされたコミットが指摘を明確に解消すると、**スレッドを自動解決**する機能にも対応しています（2026-09-11）。作成者は [[PR Coding Agent Handoff|PR のコーディングエージェントへの引き継ぎ]]や [[Agent Merge]] で未解決スレッドを委任することもできます。
