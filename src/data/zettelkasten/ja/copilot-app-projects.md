---
title: "Copilot App の Projects"
---

**Copilot App の Projects**（[[GitHub Copilot App]] でパブリックプレビュー）は、単一の独立したブランチタスクではなく、1 つ、複数、またはリポジトリなしの環境で、継続的な目標に向けた作業を調整します。

## Project の画面と作業ループ

| 画面 | 役割 |
| --- | --- |
| **Library** | セッション間で共有する仕様、デザインファイル、スプレッドシート、生成された成果物 |
| **Overview** | 並列の子エージェントセッション全体の進捗をリアルタイムに集約 |
| **Needs input** | 人間の承認ゲートや確認が必要な判断をまとめる受信トレイ |
| **Project Automations** | Project の共有コンテキストに紐づく定期実行タスク |

## Projects とセッションの使い分け

- 1 つの修正に集中する場合は、リポジトリのセッションを直接開始します。[[Copilot Connectors]] や [[Native Office Canvases]] とともに、複数リポジトリにまたがる成果を調整する場合は Project を作成します。
