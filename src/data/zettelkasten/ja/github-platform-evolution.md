---
title: "GitHub プラットフォームの進化"
---

**GitHub プラットフォームの進化**は、[[GitHub]] が共同作業のためのバージョン管理から、複数エージェントを協調させるソフトウェアデリバリーへ発展してきた過程を示します。

## 6つの節目（2008〜2026年）

| 年 | 節目 | 主な変化 |
| --- | --- | --- |
| **2008** | **プルリクエスト** | 非同期のコード共同作業とレビューを標準に |
| **2012** | **GitHub Enterprise** | チーム開発へ ID、コンプライアンス、ガバナンスを導入 |
| **2019** | **Actions と GHAS** | [[SDLC Stage 04 Test & Secure|SDLC ステージ04: テストとセキュリティ]]で CI/CD デリバリーと組み込みのコード / シークレット保護を自動化 |
| **2021** | **GitHub Copilot** | 初の主流 AI ペアプログラマーとして [[GitHub Copilot]] を導入 |
| **2025** | **Agent HQ** | タスクの委任と非同期コーディングセッションの追跡を実現 |
| **2026** | **Projects とエージェントグループ** | [[Agent HQ & Agent Teams]] で1つの目標、共有コンテキスト、並列の専門エージェントを統合 |

## 開発者の仕事の4つの時代

- **2020年まで（ファイル / 実行）**: 手動によるファイル編集とスクリプト実行。
- **2021〜2024年（提案 / 差分）**: [[Copilot Interaction Modes|Copilot の対話モード]]におけるインライン補完とチャットの差分。
- **2025年（タスク / セッション）**: クラウドと CLI のセッションへ単一タスクを委任し、[[Octoverse & Agent Era Metrics|Octoverse とエージェント時代の指標]]で示される急増を促進。
- **2026年（プロジェクト / エージェントグループ）**: [[AI Developer Platform|AI 開発者プラットフォーム]]上で、リポジトリや GUI をまたいで複数エージェントを調整。
