---
title: "GitHub Well-Architected のガードレール"
---

**GitHub Well-Architected のガードレール**は、[[Enterprise Policies|エンタープライズポリシー]]、[[Enterprise & Repo Rulesets|エンタープライズとリポジトリのルールセット]]、リポジトリの webhook、[[Copilot Managed Settings|Copilot の管理設定]]にまたがる21の具体的な設定を、[[Enterprise Governance|エンタープライズガバナンス]]の下で定めます。時間が限られる場合は、**#03**（読み取り専用の `GITHUB_TOKEN`）、**#15**（ルールセットのバイパス禁止）、**#18**（監査ログストリーミング）を優先します。

## ガードレール #01〜#11: Actions、リポジトリ、アクセス、Webhook

| # | ガードレール | 範囲 | 推奨設定と理由 |
| --- | --- | --- | --- |
| **01** | Actions の実行範囲 | `ORG` | すべてのリポジトリに無条件で許可せず、**特定のリポジトリ**に限定 |
| **02** | 許可するアクション | `ENT` | **GitHub 作成と Verified Creator** のアクションのみ許可（SHA 固定の社内リストを追加可能） |
| **03** | デフォルトのワークフロートークン | `ENT / ORG` | `GITHUB_TOKEN` を **`read-only`** に設定（初期値は読み書き可能で、漏えいすると書き込み経路をさらす） |
| **04** | PR の自動承認 | `ENT / ORG` | **無効**（デフォルトは有効。ワークフローが人間のレビューを迂回するのを防ぐ） |
| **05** | リポジトリのフォーク | `ENT / ORG` | リポジトリに明確なフォーク運用の必要性がなければ**オフ** |
| **06** | 可視性の変更 | `ENT / ORG` | リポジトリの可視性を変更できる**ユーザー**を制限 |
| **07** | Fine-grained PAT | `ENT / ORG` | 対象リポジトリとスコープを監査するため、**管理者承認フロー**を必須化 |
| **08** | [[Outside Collaborators|外部コラボレーター]] | `ENT` | **`Owners only`**（初期値は `No policy` で、メンバーが外部ユーザーを招待可能） |
| **09** | パブリックリポジトリ | `ENT` | オープンソースを別管理の専用組織に分離している場合を除き、**禁止** |
| **10** | Webhook のシークレット | `ORG / REPO` | 受信側でペイロードの HMAC 署名を検証できるよう**必ず設定** |
| **11** | Webhook の通信 | `ORG / REPO` | すべての webhook エンドポイントに **SSL / HTTPS** を強制 |

## ガードレール #12〜#21: コードの完全性、ランナー、ログ、Copilot エージェント

| # | ガードレール | 範囲 | 推奨設定と理由 |
| --- | --- | --- | --- |
| **12** | リポジトリのルールセット | `ENT / ORG / REPO` | [[Enterprise & Repo Rulesets|エンタープライズとリポジトリのルールセット]]でレビュー、ステータスチェック、ブランチ保護を強制 |
| **13** | `CODEOWNERS` | `REPO` | `.github/CODEOWNERS` で重要パスごとの所有組織チームを明示 |
| **14** | コミット署名 | `REPO` | コミットのなりすましを防ぐため**必須**（Copilot クラウドエージェントのコミットは自動署名） |
| **15** | ルールセットのバイパス | `REPO` | **禁止**（バイパスリストを空にする。バイパスがあるとルールは提案に変わる） |
| **16** | ランナーグループ | `ENT / ORG` | 各セルフホステッドランナーグループの対象を**限定されたリポジトリ群**に絞る |
| **17** | プッシュ保護のバイパス | `ORG` | シークレットスキャンのバイパスを**指定ロールとチーム**に限定（デフォルトでは `Write` を持つ全員が可能） |
| **18** | 監査ログストリーミング | `ENT` | 継続的なインシデント調査の証跡を残すため、SIEM またはクラウドオブジェクトストレージへ**設定済みにする** |
| **19** | Copilot エージェントの権限 | `ENT` | `disableBypassPermissionsMode` で全許可の YOLO モードを禁止 |
| **20** | Copilot のローカルサンドボックス | `ENT` | `sandbox`（`enabled: true`、`allowBypass: false`）を強制し、`~/.ssh` と OS Keychain を分離 |
| **21** | MCP サーバー許可リスト | `ENT` | `allowedMcpServers` に**審査済みサーバーのみ**を設定し、未承認の MCP ツールによるコード / トークンの読み取りを防止 |
