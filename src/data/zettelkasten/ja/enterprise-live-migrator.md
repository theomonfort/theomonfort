---
title: "Enterprise Live Migrator"
---

**Enterprise Live Migrator**（`ELM`、`gh elm` による Enterprise Live Migrations、GA `2026-09-01`）は、稼働中のリポジトリを [[GitHub Enterprise Server]] から [[GHE.com Data Residency|GHE.com のデータレジデンシー]]へ継続的にバックグラウンド複製します。開発者の書き込み停止は、最終切り替え時の**数分間**だけです。

## `GHES -> GHE.com` 移行における ELM と GEI の比較

同じ [[GitHub Migrations|GitHub 移行]]の実施単位で両ツールを併用し、リポジトリごとに選択できます。

| 観点 | **Enterprise Live Migrator（`ELM`）** | [[GitHub Enterprise Importer]]（`GEI`） |
| --- | --- | --- |
| **開発者の停止時間** | **切り替え時のみ（数分）**。同期中も移行元リポジトリは稼働 | エクスポート、アップロード、インポートの全期間でリポジトリを凍結 |
| **適した対象** | 停止できない大規模モノレポや最重要リポジトリ | 計画的な凍結を許容できる標準的なリポジトリ |
| **同時実行上限** | **`10`**（`GHES` インスタンスごと）、**`20`**（移行先エンタープライズごと） | 並列バッチ処理のスループットが高い |
| **Git LFS オブジェクト** | **自動移行** | 対象外（移行後に手動プッシュが必要） |
| **最低 `GHES` バージョン** | サポート対象の **`GHES 3.17+`** パッチリリース（HTTPS と外向き通信が必要） | `GHES 3.4.1+`（`3.13+` なら上限 `40 GiB`） |
| **外部ステージングストレージ** | **不要** | 外部 Blob ストレージが必要（`GHES 3.8+`） |
| **対応するクラウド移行先** | **`GHE.com`（EMU）のみ** | `github.com` と `GHE.com` の両方 |

## 前提条件、対象外項目、切り替えのガードレール

- **実行者と制限**: classic PAT を持つ `GHES` サイト管理者と `GHE.com` エンタープライズオーナーが必要です。**1回の実行で1リポジトリ**を移行し、リリースアセットは1件あたり最大 **`2 GB`** です（[[Org Transfer & Migration Limits|組織移管と移行の制限]]を参照）。
- **移行対象外のメタデータ**: 組織設定、チーム、GitHub Projects、組織の webhook、[[Enterprise & Repo Rulesets|エンタープライズとリポジトリのルールセット]]、フォークからの PR、保留中の PR レビュー、ブランチ保護のバイパス対象者は移行されません。切り替え後に [[IdP Group & Team Sync|IdP グループとチームの同期]]でチームを再作成し、マネキンを [[Enterprise Managed Users]] に再割り当てします。
- **強制プッシュとパブリックリポジトリは禁止**: ライブ複製中は強制プッシュを禁止します（`ELM` は書き換えられた Git 履歴を整合できません）。開始前に `GHES` インスタンス内の公開リポジトリをプライベートまたは内部に変更します。`GHE.com` はパブリックリポジトリを認めないためです。
