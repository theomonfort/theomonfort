title: "MCP 許可リストのガバナンス"
---

**MCP 許可リストのガバナンス**（Well-Architected ガードレール #21、管理設定の GA は `2026-08-06`、CLI のカスタムレジストリ許可リストは `2026-04-16`）は、未審査の [[MCP Servers]] にエンタープライズのコードや認証情報が渡るのを防ぎます。

## 管理設定のポリシーキー

組織 / エンタープライズの MCP ポリシーと併せて、[[Copilot Managed Settings]] 内で設定します（チームごとに `OVERRIDABLE`）。

- **`allowedMcpServers`（厳格な許可リスト）**: 記載されたサーバーだけが実行できます。リモート URL（`*` ワイルドカード対応）またはローカルの `stdio` コマンドで照合します。`[]` を指定すると外部サーバーをすべてブロックし、[[GitHub MCP Server]] などの組み込みサーバーだけが利用可能になります。
- **`deniedMcpServers`（明示的な拒否リスト）**: 許可リストに一致しても、特定の URL やコマンドをブロックします（組み込みサーバーはブロック不可）。
- **レジストリベースの許可リスト**: エンタープライズは Copilot CLI と VS Code の参照先を社内 MCP レジストリ URL に設定でき、開発者は [[MCP Configuration]] で承認済みサーバーのみをインストールできます。
