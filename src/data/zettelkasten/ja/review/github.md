**GitHub** は、人間、ボット、コーディングエージェントによるすべての変更が、`main` に入る前に構造化されたコードレビュー、自動チェック、ブランチガバナンスを通過する共同作業のプラットフォームです。

## GitHub のコードレビューとマージの柱

- **ブランチと PR のライフサイクル**: [[GitHub Flow]] の短命な機能ブランチが [[Pull Requests]] に集約されます（2026年は月間約9,000万件のマージ）。差分の議論、自動 CI、マージ戦略を1つのワークスペースにまとめます。
- **人間による所有責任とレビューの振り分け**: [[CODEOWNERS]] のパスに基づく管理責任により、マージ前に適切な領域のメンテナーやチームへ変更を送ります。
- **スタックと自律的なマージ**: [[Stacked Pull Requests]] の依存関係を持つ層状ブランチ、[[Merge Queue]] の順序付き CI バッチ処理、[[Agent Merge]] による最終段階の障害解消。
- **AI によるレビュー**: [[Copilot Code Review]] のエージェント型コンテキスト収集、インライン提案、Effort レベル。
- **ブランチガバナンスと PR ゲート**: [[PR Rulesets]] によるリポジトリ、組織、エンタープライズの上位からの適用と、それを支える [[Code Scanning PR Merge Protection]]、[[Code Quality PR Findings]]。
