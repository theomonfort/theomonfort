---
title: "Spaces のソース種別と共有"
---

**Spaces のソース種別と共有**は、[[Copilot Spaces]] が添付された資料を取得する方法と、GitHub リポジトリのアクセス権を適用する方法を定めます。

## ソース種別ごとの取得動作

| ソース種別 | Copilot の処理方法 | 適した用途 |
| --- | --- | --- |
| **リポジトリ** | リポジトリ全体を読み込むのではなく、クエリごとに関連する部分を検索して取得 | 大規模コードベース、横断的なアーキテクチャの質問 |
| **ファイル / フォルダー** | 固定したファイルの内容をターン間で一貫して優先 | API の契約、仕様、主要モジュール |
| **アップロードしたファイル** | アップロード時点の静的なスナップショットを読む | 外部のスプレッドシート、図、会話記録 |

## 所有権とアクセスモデル

- **Organization の Spaces**：`Admin`、`Editor`、`Viewer`、`No access` ロールを使い、Organization メンバー、チーム、特定ユーザーと共有します。
- **個人の Spaces**：非公開、指定ユーザーとの共有、閲覧専用のリンク共有が可能です。
- **権限昇格なし**：閲覧者が見られるのは、自分がすでに読み取り権限を持つ GitHub リポジトリのソースだけです。[[Spaces IDE Integration via MCP|MCP による Spaces の IDE 統合]]を通じたアクセスにも適用されます。
