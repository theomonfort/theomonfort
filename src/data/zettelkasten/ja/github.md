**GitHub** は、**2億2,500万人以上の開発者**が集う世界最大の AI ネイティブな開発者プラットフォームです（**毎秒1人を超える新規開発者**が参加し、**25億件の公開コントリビューション**。2026年9月の Octoverse）。計画、複数エージェントによるコーディング、PR レビュー、セキュリティ、運用、エンタープライズガバナンスを1つのグラフに統合します。

## SDLC 全体を統合するプラットフォーム領域

- **導入とプラットフォーム戦略**: [[GitHub Platform Evolution]] で見る20年間の変化、[[Octoverse & Agent Era Metrics]] の世界規模の開発速度、[[Git Infrastructure & Scale]] の基盤規模、5段階の [[AI Developer Platform]]、Universe 2026 の [[Innovate Pillar]]、[[Scale Pillar]]、[[Trust Pillar]]、そして [[GitHub Copilot]]、[[Copilot Fusion]]、[[Agent HQ & Agent Teams]]、[[Copilot Proxy]]。
- **計画と Copilot のカスタマイズ**: [[GitHub Discussions]]、[[Issues & Sub-issues]]、[[GitHub Projects]] によるチームの認識合わせと、[[Custom Instructions]]、[[Agent Skills]]、[[Agent Plugins]]、[[MCP Servers]]、[[Copilot Connectors]]、[[Custom Agents]]、[[Hooks]] の組み合わせ。
- **開発とエージェントの利用環境**: [[Copilot in VS Code]]、[[VS Code Agents Window]]、[[Copilot CLI]]、[[Copilot Cloud Agent]]、[[GitHub Copilot App]]、[[Partner Agents]]、[[GitHub Codespaces]]、[[Copilot Spaces]] にまたがる同期 / 非同期のコーディング。
- **レビューと自律的なマージ**: [[Pull Requests]] による [[GitHub Flow]] に沿った共同作業、[[CODEOWNERS]] による領域の所有責任、[[Stacked Pull Requests]]、[[Merge Queue]]、[[Agent Merge]]、[[Copilot Code Review]]、[[PR Rulesets]]。
- **テストとセキュリティ**: [[GitHub Actions]] のイベント駆動 CI/CD、[[GHAS]]（[[Code Security]] と [[Secret Protection]]）、独立製品の [[Code Quality]]、[[Rulesets & Merge Protection]]。
- **運用と継続的な学習**: Markdown で記述する [[Agentic Workflows]]、永続的な [[Copilot Memory]] と [[Copilot Dreaming]]、組織全体の [[Copilot Metrics]]、[[Packages & GitHub Apps]]。
- **管理と FinOps**: [[GitHub Enterprise Cloud]]、[[Enterprise Managed Users]]、[[GHE.com Data Residency]]、[[GitHub Enterprise Server]] のホスティング選択と、それを支える [[SAML & OIDC SSO]]、[[GHE & Copilot Licenses]]、[[Usage-Based Billing]]、[[Cost Centers]]、[[Budgets & Spending Limits]]、[[Enterprise Governance]]、[[Copilot Managed Settings]]、[[GitHub Migrations]]。
