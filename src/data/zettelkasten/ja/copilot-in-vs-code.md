title: "VS Code の Copilot"
---

**VS Code の Copilot** は、[[GitHub]] 上で、エディターに並ぶ Chat ビューと共通の **Copilot** 実行ハーネスを組み合わせます（`2026-10-28` 以降の既定。従来のエディター専用 `Local` ハーネスを置き換えます）。

## 既定の Copilot ハーネスの機能

- **サンドボックスと支援付き権限**: ファイルとネットワークの境界内でビルドとテストを実行します。日常的な呼び出しは自動承認し、機密性の高い操作は [[Local & Cloud Sandboxes]] を通じて確認を求めます。
- **統一された実行環境**: スキル、フック、プラグイン、[[Copilot Connectors]]、[[Copilot Fusion]] を [[Copilot CLI]] と [[GitHub Copilot App]] で共有します。
- **対話型キャンバス**: セッション開始前に `chat.canvases.enabled` を有効にすると、[[Native Office Canvases]] とともにタスクボードや図で共同作業できます。
- **セッションの継続**: エディターの Chat、[[VS Code Agents Window]]、[[VS Code Session Targets]]、[[Connected Cloud Continuity]] の間を、[[VS Code Chat Shortcuts & Commands]] で円滑に移動できます。
