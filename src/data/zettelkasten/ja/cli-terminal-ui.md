---
title: "CLI のターミナル UI"
---

**CLI のターミナル UI**（[[Copilot CLI]] で `/experimental on` により有効化）は、テーマに対応し、スクリーンリーダーでも利用できるターミナル画面です。シェルを離れずにリポジトリのコンテキストを参照できます。

## リポジトリ内のタブ移動

| タブ | 参照できる内容 |
| --- | --- |
| **Session** | 現在の対話型 Copilot 会話（既定） |
| **Issues** | トリアージや [[Cloud Agent Entry Points]] での利用が可能なリポジトリの Issue |
| **Pull requests** | リポジトリの開いているプルリクエスト |
| **Gists** | 個人の GitHub Gist |

## カスタマイズ

- [[CLI Slash Commands & Fleet]] とともに `/theme` を実行し、意味に応じたターミナルのカラーパレットを確認、切り替えできます。
