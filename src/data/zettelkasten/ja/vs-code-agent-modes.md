---
title: "VS Code のエージェントモード"
---

**VS Code のエージェントモード**は、ユーザーが選べる会話モードと、内部で呼び出される [[Subagents|サブエージェント]]を区別します。これらはユーザー作成の [[Custom Agents|カスタムエージェント]]と併用されます。

## 選択できるモードと内部ヘルパー

| 利用環境 | モード / ツール | 動作 |
| --- | --- | --- |
| **Copilot Chat / VS Code** | **Agent** | ファイル編集とツール実行を使って、複数ステップのタスクを実装 |
| **Copilot Chat / VS Code** | **Plan** | コードベースを調査し、編集前にユーザーの承認を得るための複数ステップの実装計画を提示 |
| **Copilot Chat / VS Code** | **Ask** | 編集せず、読み取り専用で質問に回答し、コードを調査 |
| **VS Code 内部（`1.110+`）** | **`searchSubagent`** | 分離された並列コードベース検索を実行し、呼び出し元に要約を返す |

**実装の詳細**：以前は独立していた VS Code の `Explore` の動作は、現在 `searchSubagent` を通じて実行されます。そのプロンプトとツールのロジックは、編集可能な `.agent.md` ファイルではなく、内部の TypeScript / TSX にあります。
