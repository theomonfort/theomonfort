---
title: "Git ワークツリーによる分離"
---

**Git ワークツリーによる分離**は、[[VS Code Agents Window|VS Code の Agents ウィンドウ]]と [[GitHub Copilot App]] で、並列の各エージェントセッションに専用の Git ブランチと作業ディレクトリを与えます。同時に動くエージェントが互いの編集を上書きするのを防ぎます。

## 並列セッションの操作

| ショートカット / 操作 | 動作 |
| --- | --- |
| **`Alt+Enter`** | 現在のセッションにフォーカスを残したまま、プロンプトをバックグラウンドで送信 |
| **`⌘N` / `Ctrl+N`** | 新しい分離されたセッションを開始 |
| **`⌘1`-`⌘9` / `Ctrl+1`-`Ctrl+9`** | グリッド位置で指定したセッションへ直接移動 |
| **`Open to the Side` / `Pin`** | ピン留めしたビューを置き換えずに、複数セッションを横並びで表示 |

## プルリクエストとタスクの自動化

- **New Session from Pull Request** は、オープンな PR を追跡するワークツリーをチェックアウトし、差分とコメントをあらかじめ読み込みます。新しいコミットはその PR へ直接同期されます。
- セッションごとに起動時の **Task** を設定すれば、新規ワークツリーの作成時に依存関係を自動インストールできます。
- **ワークツリーとサンドボックスは別**: ワークツリーは Git ブランチを分離し、[[Local & Cloud Sandboxes|ローカルとクラウドのサンドボックス]]はファイルシステムとネットワークの実行を制限します。[[Agents Window Five Panels|Agents ウィンドウの5つのパネル]]内でも確認できます。
