**Innovate の柱**（`01 / Capability`）は、[[GitHub]] の Universe 2026 における3つの戦略の柱の1つ目です。最初のアイデアからソフトウェアの出荷まで、[[GitHub Copilot]] が [[AI Developer Platform|AI 開発者プラットフォーム]]全体で役立つようにすることに重点を置きます。

## Universe 2026 の提供状況（2026-11-11 確認）

| リリース | 状態 | 主な機能 |
| --- | --- | --- |
| **Copilot App** | `Available` | 目標指向のデスクトップアプリ。Projects と Computer Use はパブリックプレビュー（[[Agent HQ & Agent Teams]]、[[Copilot Surfaces]]） |
| **Copilot Fusion** | `GA` | IDE、CLI、App を横断する複数モデルのルーティングと Effort に基づくオーケストレーション（[[Copilot Fusion]]） |
| **Copilot Automations** | `Available` | 共有可能で再利用できるチーム向けエージェントワークフローをアプリで順次提供（[[Copilot Automations]]） |
| **Code Review Max** | `Preview` | より深いエージェント型 PR レビュー。**Copilot Approvals** は `GA`（[[SDLC Stage 03 Review]]） |
| **Memory / Dreaming** | `Mixed` | **Copilot Memory** は `GA`、**Dreaming** は `Public Preview`（[[SDLC Stage 05 Operate]]） |

[[Scale Pillar|Scale の柱]]と [[Trust Pillar|Trust の柱]]と組み合わせることで、Innovate は単発の AI プロンプトを、継続的な複数エージェントの共同作業へ変えます。
