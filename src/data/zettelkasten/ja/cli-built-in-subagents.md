---
title: "CLI の組み込みサブエージェント"
---

**CLI の組み込みサブエージェント**は、[[Copilot CLI]] の分離されたコンテキストウィンドウで専門タスクを実行します。コードベースの探索、テスト出力、詳細なレビューによってメインセッションが肥大化するのを防ぎます。

## 6 つの組み込みエージェント

| エージェント | 役割 |
| --- | --- |
| **Explore** | 親のコンテキストを圧迫せず、高速な読み取り専用のコードベース分析と Q&A を実行 |
| **Task** | ビルド / テストを実行し、成功時は簡潔な要約、失敗時は完全なログを返す |
| **General purpose** | 複雑な複数ステップのサブタスクに、全機能の推論と編集で対応 |
| **Code review** | スタイル上の雑音ではなく、実際のバグに焦点を当てた有用な差分レビュー |
| **Research** | 検証済みの引用を伴う、複数リポジトリと Web の調査 |
| **Rubber duck** | [[Rubber Duck Review]] で使用する別モデルによる批評役 |

## 確認とモデルの上書き

- [[CLI Slash Commands & Fleet]] の `/subagents` で組み込みエージェントを確認し、エージェントごとのモデルを上書きできます。または、ローカルの `*.agent.yaml` 定義を `~/.copilot/pkg/<platform>/<version>/definitions/` で参照します。
