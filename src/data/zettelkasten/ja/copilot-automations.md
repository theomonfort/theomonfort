---
title: "Copilot の自動化"
---

**Copilot Automations**（`Available`、[[Innovate Pillar]] の一部として Universe `2026-10-28` で発表）は、[[GitHub Copilot]] と Copilot App 内で、繰り返し実行するエージェント型ワークフローをチームがパッケージ化して共有する機能です。

## 主な機能

- **チーム共有ワークフロー**: 繰り返すトリアージ、レポート、レビューの定期確認、リポジトリ横断の保守プロンプトを、チームの [[Copilot Surfaces]] 全体で使える永続的な自動化に変換します。
- **Project とセッションの統合**: [[Agent HQ & Agent Teams]] の永続的な Projects と連携し、スケジュールやトリガーに応じて専用セッションや子セッションを起動します。
- **リポジトリ運用との接続**: [[SDLC Stage 05 Operate]] と [[Scale Pillar]] における GitHub Actions 上の Agentic Workflows を補完します。

## 連携する自動化の基本機能

- リポジトリ単位の [[Agentic Workflows]]（[[GitHub Actions]] 上）と、[[GitHub Copilot App]] および [[Copilot App Projects]] の複数リポジトリにまたがる調整を補完します。
