---
title: "GitHub Discussions"
---

**GitHub Discussions** は、[[GitHub]] に組み込まれたフォーラムです。アーキテクチャの質問、初期段階のアイデア、チームへの告知など、直ちに単一のタスク担当者を決める必要がない会話に使います。

## 主な機能

- **ベストアンサー付き Q&A**: 確認済みの解決策を回答としてマークし、繰り返される技術的な質問を検索可能なチームの知識にします。
- **告知**: コードのすぐ近くでリリースノート、RFC、ロードマップの方向性を共有します。
- **投票**: メンテナーやプロダクトチームの合意をすばやく集めます。
- **ワンクリックで Issue 化**: アイデアが実行段階に達したら、結論の出たスレッドを直接 [[Issues & Sub-issues|Issue とサブ Issue]]へ変換します。

## 実例

- GitHub 自身も、製品フィードバックやコミュニティ Q&A に `github.com/orgs/community/discussions` の Discussions を使っています。
