title: "GitHub Copilot App"
---

**GitHub Copilot App**（`macOS / Windows / Linux`、Copilot の各プランで利用可能）は、[[GitHub]] の目標指向のデスクトップワークスペースです。開発者は、並列のコーディングエージェント、外部コンテキスト、ファイル、プルリクエストを1か所で調整できます。

## 協働モードと分離

| セッションモード | 開発者の役割 |
| --- | --- |
| **Interactive** | エージェントを段階的に指示する |
| **Plan** | コード変更の開始前に、構造化された計画を確認して承認する |
| **Autopilot** | 範囲を定めた目標を委任し、完成した差分や成果物を確認する |
