title: "GitHub"
---

**GitHub** は、計画とコーディングから PR レビュー、セキュリティ、運用まで、ソフトウェアのライフサイクル全体を支える AI ネイティブな開発者プラットフォームです。

コードを書いてから数日後に外部コンソールでセキュリティやコードの健全性を確認するのではなく、リポジトリ、PR、エージェントがすでにある場所で直接チェックを実行します。

## テストとセキュリティの柱

- [[GitHub Actions]]: SDLC 全体で、使い捨て VM 上の単体 / E2E テスト、ビルド、デプロイを実行する標準の CI/CD とイベント駆動の自動化。
- [[GHAS]]（GitHub Advanced Security）: 認証情報の漏えいや脆弱なコードからリポジトリを保護する有料のセキュリティスイート。
- [[Code Quality]]: マージ前にコードの信頼性と保守性を保ち、テストでカバーする独立製品。
- [[Rulesets & Merge Protection]]: PR に CI チェック、セキュリティ、品質、ライセンスのルールを適用する、リポジトリ、組織、エンタープライズの集中管理されたブランチゲート。
