---
title: "GitHub 上の Claude Code"
---

**GitHub 上の Claude Code** は、Anthropic のコーディングハーネスを [[Copilot in VS Code]] と [[Copilot Cloud Agent]] にネイティブ統合します。[[Partner Agents]] の一部として、[[Partner Agent Governance]] によって管理されます。

## VS Code と Cloud Agent での実行

| 環境 | 設定と機能 |
| --- | --- |
| **VS Code（拡張機能のインストール不要）** | `Claude` を [[VS Code Session Targets]]（`New Chat (+)`）で直接選択します。Claude Agent SDK を実行し、`Auto`、`Claude Opus 4.5/4.6/4.7`、`Claude Sonnet 4.5/4.6`、権限モード（`Edit automatically`、`Request approval`、`Plan`）、Claude のスラッシュコマンドを利用できます |
| **Cloud Agent** | **Claude Agent SDK** を選択し、Actions ランナー上で深い多段階の推論を実行します。[[Cloud Agent Validation Tools]] で保護され、Copilot AI クレジットで課金されます |
