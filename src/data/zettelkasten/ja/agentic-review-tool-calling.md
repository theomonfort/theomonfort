---
title: "エージェント型レビューのツール呼び出し"
---

**エージェント型レビューのツール呼び出し**（**2026-03-05** 提供開始）は、[[Copilot Code Review]] を差分だけを読む仕組みから、一時的な GitHub Actions 環境内で複数ステップのツール呼び出しを実行するエージェントへと拡張します。

## エージェントによるコンテキスト収集

| 機能 | Copilot が差分以外に調べる対象 |
| --- | --- |
| **リポジトリ全体の探索** | 読み取りと検索のツールを呼び出し、変更されていないファイルを開き、パッケージをまたいで呼び出し元と呼び出し先を追跡し、ディレクトリの規約を確認します |
| **決定論的なリンターと SAST のシグナル** | LLM の推論と決定論的な静的解析（ESLint、コンパイラー / 型チェック、[[Code Scanning PR Merge Protection]] の CodeQL シグナルなど）を組み合わせ、誤検知を減らします |
| **カスタムルールへの準拠** | [[Review Custom Instructions]] からリポジトリ単位とパス単位のルールを、[[Custom Agents in Code Review]] から専門のペルソナを読み込みます |
| **監査可能性** | GitHub Actions のワークフローログとエージェントセッションの記録で、ツール呼び出しと推論の手順を確認できます |

## 実行環境とフォールバック

- **ランナーのガバナンス**: [[Review Runner & Quota Governance]] で設定した標準ランナー、Larger Runners、セルフホストランナーで実行します（`copilot-setup-steps.yml` で事前インストールするカスタムツールチェーンも含みます）。
- **Actions 無効時のフォールバック**: リポジトリで GitHub Actions が無効、または利用できない場合、[[Copilot Code Review]] はプロジェクト全体へのツール呼び出しを使わず、差分に限定したレビューへ切り替わります。
