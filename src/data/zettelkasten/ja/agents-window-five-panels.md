---
title: "Agents Window の 5 つのパネル"
---

**Agents Window の 5 つのパネル**は、[[VS Code Agents Window]] の固定レイアウトを構成します。どのパネルも、その時点でフォーカスされているセッションに動的に追従します。

## 5 つのパネル

| パネル | 内容 |
| --- | --- |
| **セッション一覧** | ワークスペースごとにまとめたすべての現在と過去のセッション、およびワークスペースを持たない `Chats` |
| **カスタマイズ** | エージェント、スキル、指示、フック、MCP サーバー、プラグインをまとめて確認するインスペクター |
| **チャット領域** | アクティブなセッションの会話、プロンプト入力欄、[[VS Code Chat Shortcuts & Commands]] |
| **変更** | ブランチ、未コミット、全体、または直前のターンの差分と、組み込みの Git 操作 |
| **ファイル** | 変更されたファイルだけでなく、セッションの [[Git Worktree Isolation]] チェックアウト内のファイルツリー全体 |

## ワークスペースを持たないクイックチャット

- クイックチャット（`⌘K ⌘N` / `Ctrl+K Ctrl+N`）は、リポジトリに紐づかず `Chats` グループに配置されます。フォーカスされている間は、**ファイル**と**変更**パネルが自動で非表示になります。
