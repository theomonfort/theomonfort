**Git インフラストラクチャとスケール**は、共有リポジトリで数千のコーディングエージェントが同時に動作できるようにする、[[GitHub]] の2026年のコンピューティング、ストレージ、ネットワーク、Git コアエンジンへの投資を扱います。

## 2026年に追加した容量

| インフラストラクチャ層 | 2026年の拡張 | 目的 |
| --- | --- | --- |
| **コンピューティング** | **CPU コアを400万追加** | Actions ランナー、クラウドサンドボックス、エージェント処理の実行 |
| **ストレージ** | 高速ストレージを **160 PB 追加** | 低遅延の Git オブジェクトストア、キャッシュ、パッケージレジストリ |
| **ネットワーク** | ネットワーク容量を **50 Tb/s 追加** | 高スループットのクローン、フェッチ、プッシュ、アーティファクト転送 |

## 「高負荷エージェント」に対応する Git の再設計

- **モノレポの負荷ベンチマーク**: GitHub は Git の主要な書き込み経路を再設計し、単一のモノレポに対して**5,000の「高負荷エージェント」が同時に**動き、**毎秒7,200回の書き込み**を継続できるようにしました。[[Octoverse & Agent Era Metrics|Octoverse とエージェント時代の指標]]で示された指数関数的な成長に対応するものです。
- **Azure 移行のロードマップ**: Universe 2026 の [[Scale Pillar|Scale の柱]]の下、GitHub は Git インフラストラクチャ全体の Azure への移行を進めています。[[Agent HQ & Agent Teams]] と併せて、**2027年初頭**の完了を目指しています。
