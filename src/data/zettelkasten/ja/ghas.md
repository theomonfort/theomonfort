**GitHub Advanced Security（GHAS）**は、[[GitHub]] に直接組み込まれたセキュリティスイートです。開発者が誤って漏えいさせたり混入させたりする**認証情報**と**脆弱なコード**を、リポジトリ内でスキャンします。

## 2つの独立した製品

GHAS は2つの独立製品として提供され、アクティブコミッター単位で課金されます。対象は、過去90日間に有効化済みリポジトリへプッシュしたユーザーです。パブリックリポジトリでは主要機能を無料で利用できます。

- [[Secret Protection]]（アクティブコミッター1人あたり月額 $19）: API キー、トークン、パスワードが Git 履歴に入るのを防ぎます。
- [[Code Security]]（アクティブコミッター1人あたり月額 $30）: 自社ソースコードとオープンソース依存関係の脆弱性を検出します（両製品の合計は月額 $49）。

## 大規模なガバナンスと展開

- [[Risk Assessments|リスク評価]]: 購入前に、組織全体のシークレットリスクとコードセキュリティリスクを無料で棚卸しします。
- [[Security Configurations|セキュリティ構成]]: 単一のポリシーから全組織と全リポジトリに設定を展開し、適用を強制します。
- [[Security Overview|セキュリティ概要]]: 組織とエンタープライズを横断して、検出、修正、カバレッジ、リスク、[[Public Monitoring|公開リポジトリの監視]]を追跡します。
