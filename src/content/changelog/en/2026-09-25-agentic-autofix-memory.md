### Key takeaways

- **Reuses context**: existing memories help autofix understand your repository's secure development patterns.
- **Learns from fixes**: new fix patterns become memories that can help with later alerts, Copilot code review, and Copilot cloud agent.
- **Requires Copilot Memory to be enabled**. Both agentic autofix and Copilot Memory remain in public preview.
