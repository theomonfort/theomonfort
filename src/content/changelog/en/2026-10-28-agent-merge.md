### From the merge box

- **Watch and fix**: choose failing Actions workflows, merge conflicts, or both. Copilot starts in a cloud development environment when a selected blocker appears.
- **Default for your PRs**: enable Agent Merge in Copilot settings if you want it to watch every pull request you open.
- **Beyond the editor**: already available in Copilot app and VS Code, Agent Merge is now integrated directly into pull requests on GitHub.

### Fixing is not the same as merging

Agent Merge keeps the PR ready. **Auto-merge is a separate option**: enable it if you also want GitHub to merge once all requirements are met. Required reviews and checks still apply.

Cloud Agent Merge requires a paid Copilot plan and is subject to organization and enterprise policies.
