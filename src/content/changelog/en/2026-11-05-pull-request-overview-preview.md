### See what's blocking and what to do next

The new Overview page brings merge status and next actions to the top of a pull request in a compact readiness summary.

- **Check readiness at a glance**: See checks, comments, and approvals, then take action on blockers or merge when requirements are met.
- **Focus the conversation**: Filter comments to unresolved threads or your own comments, and sort newest first.
- **Catch up on activity**: Use the summary to find review comments, review requests, and other updates.
- **Act from the header**: Mark a draft ready for review or close the pull request, depending on your permissions.

This is an opt-in public preview. Select **✨ Try the Overview page** in the pull request header to try it. Use the same menu to return to the classic overview.
