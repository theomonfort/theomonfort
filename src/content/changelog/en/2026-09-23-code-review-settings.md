### Key takeaways

- **Personal settings**: [profile → Copilot settings → Copilot → Code review](https://github.com/settings/copilot/code_review). Configure automatic reviews for PRs you create or coauthor, with separate toggles for drafts and new pushes.
- **Default review effort**: choose Lite or Balanced. You can override it when manually requesting a review.
- **Enterprise defaults**: Enterprise → AI controls → Agents → Copilot code review → Default review effort level. Choose Lite, Balanced, or the GitHub default for organization-owned repositories. Organizations and repositories can override this.
