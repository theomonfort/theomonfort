### Access and usage are separate

- **Enterprise-licensed users**: Copilot access can be included with GitHub Enterprise, with the same features and models as Copilot Enterprise.
- **No included monthly AI credits**: usage draws from the enterprise budget from the first request. Included access does not mean unlimited AI usage.
- **When budget runs out**: code completion and next edit suggestions keep working. Chat, code review, and cloud execution require available budget; the seat itself is not removed.
- **Users without a GitHub Enterprise license**: Copilot Standalone provides the same access at $10 per user per month, without monthly AI credits per seat (announced October 28, 2026).

### Who can use it?

Available for **GitHub Enterprise Cloud customers working with a GitHub or Microsoft account team**, through a new account or a transition arranged with that team.

Self-serve availability will roll out in stages. Existing self-serve subscriptions are unchanged, and Copilot Business and Copilot Enterprise remain available.
