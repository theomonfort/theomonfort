### Key takeaways

- **Your own issue views**: save personalized views on a repository's Issues page and return to them without rebuilding the same search.
- **Private to you**: these saved views are personal, not shared with the rest of the team.
- **Relates to**: issue relationships now work across REST and GraphQL APIs, webhooks, timeline events, and Issues / Projects search.
