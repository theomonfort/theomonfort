### ブロッカーと次のアクションをすぐに確認

新しい Overview ページでは、Pull Request のマージ状況と次のアクションを、コンパクトなサマリーとしてページ上部に表示します。

- **マージ可否をひと目で確認**：チェック、コメント、承認状況を確認し、ブロッカーに対応するか、要件が満たされたらマージできます。
- **会話に集中**：未解決のスレッドや自分のコメントに絞り込み、コメントを新しい順に並べ替えられます。
- **最近の動きを把握**：サマリーからレビューコメント、レビュー依頼、その他の更新を確認できます。
- **ヘッダーから操作**：権限に応じて、ドラフトをレビュー可能にしたり、Pull Request をクローズしたりできます。

この機能はオプトイン形式のパブリックプレビューです。Pull Request のヘッダーにある **✨ Try the Overview page** を選択して試せます。同じメニューから従来の Overview に戻せます。
