### 覚えておきたいこと

- **個人設定**：[プロフィール → Copilot settings → Copilot → Code review](https://github.com/settings/copilot/code_review)。自分が作成または共同作成した PR の自動レビューを設定。ドラフトと追加 push は個別に切り替え可能。
- **レビューの深さの既定値**：Lite または Balanced を選択。手動でレビューを依頼する際は変更可能。
- **Enterprise の既定値**：Enterprise → AI controls → Agents → Copilot code review → Default review effort level。組織所有のリポジトリに Lite、Balanced、GitHub の既定値を設定。組織やリポジトリで上書き可能。
