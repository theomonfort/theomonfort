### 覚えておきたいこと

- **今から設定可能**：AI Controls → Copilot → Default policy for new features で、有効、無効、組織に委任を選択。
- 既存と今後の対象 GA 機能に適用。**Copilot コードレビューと MCP サーバーも対象**。
- **明示的な機能設定は維持。プレビュー機能は引き続きオプトイン。**

[対象範囲と例外（公式ドキュメント）](https://docs.github.com/copilot/concepts/enterprise/default-availability)
