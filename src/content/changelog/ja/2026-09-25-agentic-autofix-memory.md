### 覚えておきたいこと

- **既存の知識を活用**：リポジトリ固有の安全な開発パターンを、メモリから参照して修正に役立てます。
- **修正から学習**：新しい修正パターンを保存。後続のアラート対応や Copilot コードレビュー、Copilot cloud agent でも活用できます。
- **Copilot Memory の有効化が必要**。Agentic Autofix と Copilot Memory は、どちらもパブリックプレビューです。

[Copilot Memory（公式ドキュメント）](https://docs.github.com/enterprise-cloud@latest/copilot/concepts/agents/copilot-memory)
