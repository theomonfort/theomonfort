このセクションでは、以下のテンプレートリポジトリを複製してハンズオン用リポジトリを作成し、それを **Codespace** で開いて作業を始めます。Codespace が使えない場合は、ローカルにクローンして作業してください。

**プロジェクトURL**: [https://github.com/theomonfort/Github-copilot-workshop](https://github.com/theomonfort/Github-copilot-workshop)

### 2.1 — ハンズオン用リポジトリを作成する

1. プロジェクト URL をブラウザで開く
2. 右上の **Use this template** ボタンをクリックし、**Create a new repository** を選択

![Use this template → Create a new repository](/theomonfort/handson/img/use-this-template-dropdown.png)

3. リポジトリ作成画面で以下を設定：
   - **Owner**: テスト用リポジトリを自由に作成できる **Organization**（Copilot / Actions / GHAS / Codespaces が有効）を選択
   - **Repository name**: 任意の名前（例: `hands-on-yourname`）
   - **Visibility**: **Private** を選択
   - **Include all branches** はオフのままにします。下記のチェックポイントも含め、`main` のコピーだけで利用できます。

4. **Create repository** をクリック

![Create repository ボタンをクリック](/theomonfort/handson/img/create-repository-form.png)

### 2.2 — リポジトリを開く

作成したリポジトリを開発環境で開きます。**オプション 1（Codespaces）** を推奨しますが、使えない場合は **オプション 2（ローカル）** でも進められます。

#### オプション 1：Codespaces（推奨）

1. 作成したリポジトリのページで、緑色の **Code** ボタンをクリック
2. **Codespaces** タブを選択
3. **Create codespace on main** をクリック

<Aside type="negative">

Codespace の起動には数分かかる場合があります。DevContainer のビルドが完了するまでお待ちください。

</Aside>

#### オプション 2：ローカル

1. VS Code で **ターミナル** を開く（メニュー **Terminal → New Terminal**、または `` Ctrl+` ``）
2. リポジトリページの緑色の **Code** ボタン → **Local** タブ → **GitHub CLI** タブを開き、コピー用のクローンコマンドをコピーする

   ![Code → Local → GitHub CLI のクローンコマンドをコピー](/theomonfort/handson/img/clone-github-cli.png)

3. ターミナルに貼り付けてローカルにクローンする：

   ```bash
   gh repo clone <owner>/<repo-name>
   ```

4. クローンしたフォルダを VS Code で開く：

   ```bash
   code -r <repo-name>
   ```

<Aside type="negative">

ローカルで作業する場合は、Node.js 22 / GitHub CLI（`gh`）/ Copilot CLI（`@github/copilot`）/ gh-aw など、DevContainer に含まれるツールをご自身の環境に用意する必要があります。

</Aside>

いずれのオプションでも、DevContainer が Node.js 22 環境をセットアップし、以下が事前にインストールされます（ローカルの場合は DevContainer 対応の拡張機能を使うか、手動でご用意ください）：

- GitHub Copilot & Copilot Chat 拡張機能
- GitHub CLI（`gh`）
- GitHub MCP Server（ワークスペースのルートの `.mcp.json`。次のステップで確認し、Context7 を追加）
- Copilot CLI（`@github/copilot`）
- gh-aw（Agentic Workflow CLI）

### 2.3 — 題材コンテンツを確認する

`src/content/playbook/` に、GitHub / Copilot に関する複数の Markdown ファイルが配置されています。これらが今日のサイトの題材です。各ファイルの frontmatter には `title` / `summary` / `icon` / `color` と、SDLC の `category`（introduction / plan / develop / review / secure / operate など）が定義されています。さらに、サイト構築に使えるアイコンや画像（惑星画像など）のアセットも `public/` に用意されています。

<span id="checkpoints"></span>

<Aside type="reference">

**チェックポイントから始める：** **自分で作成したリポジトリ**のルートのターミナルで、`./checkpoint1`（PLAN + 基本サイト、Review / Cloud Agent の前）、`./checkpoint2`（+ プレゼン機能、Test & Secure の前）、`./checkpoint3`（+ テスト / CI、CLI / Operate の前）のいずれかを実行します。各コマンドは単独で使えます。先にエディタの未保存内容を保存してください。スクリプトは自分のリモート `main` から新規ブランチと PR を作り、スナップショットのファイルだけを取り込みます。マージはしません。stash が表示された場合は参照を控え、置換 / 削除の差分を確認してください。リポジトリ設定はコピーされません。`checkpoint1` は [Part 6 の Issue カタログ](/theomonfort/handson/code-copilot-chat/#66--改善点を-issue-化する)も準備するので、重複作成せず再利用してください。

**サイトを起動する：** 準備されたブランチで `npm ci && npm run dev` を実行し、Codespaces の転送ポートまたは表示されたローカル URL から `/playbook` を開きます。PR のマージ前に試せます。スクリプトは依存関係のインストールやサーバー起動を行いません。依存関係が変わっていなければ、次回の起動は `npm run dev` だけで十分です。古いテンプレートのコピーにはスクリプトがない場合があります。[チェックポイントの README](https://github.com/theomonfort/Github-copilot-workshop#チェックポイントから-pr-を作る--create-a-checkpoint-pr) を参照してください。

</Aside>
