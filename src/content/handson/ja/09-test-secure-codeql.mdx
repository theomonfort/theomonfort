### 11.1 — CodeQL を有効化する

1. リポジトリの **Settings** → **Security and quality** → **Advanced Security**
2. **Tools** → **CodeQL analysis** → **Set up** → **Default** → **Enable CodeQL**

<Aside type="negative">

**注意**: CodeQL はデフォルトブランチに存在する言語のみスキャンします。最初の Astro PR をマージしてから CodeQL を有効化すると、以降の Push / PR で TypeScript / JavaScript の自動スキャンが実行されます。

</Aside>

<Aside type="positive">

**ポイント**:

- **検出内容**: CodeQL は静的解析で XSS / SQL Injection などのセキュリティ脆弱性を検出します。
- **実行タイミング**: 有効化直後にデフォルトブランチ全体を初回スキャン → その後はデフォルトブランチへの push、PR、週次スケジュールで自動実行されます（PR のときだけではありません）。
- **結果の確認場所**: リポジトリの **Security** タブ → **Code scanning** から全アラートを確認できます。PR では該当行に直接コメントが付きます。

</Aside>

[Part 9](/theomonfort/handson/test-secure-actions/) のテストの後に、PR の E2E と CodeQL のチェックを比較し、[GHAS スライド](/theomonfort/playbook/github-advanced-security/?present=1)を開きます。依存関係のセキュリティに加え、コードスキャンとシークレット保護を説明してください。機能テストの成功だけではセキュリティは保証できません。

基本コースは [Part 14: Operate](/theomonfort/handson/operate-agentic-workflow/) に進みます。高度な機能と AI 駆動開発のこれからを先に体験したい場合は、任意で [Part 12: Copilot App / Projects](/theomonfort/handson/code-copilot-app/) と、動作する3Dがあれば [Part 13: CLI / 環境音](/theomonfort/handson/code-cli/) を試してください。
