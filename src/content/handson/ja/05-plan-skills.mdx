<Aside type="reference">

**📖 参考**: [プレイブック / Agent Skills](https://theomonfort.github.io/theomonfort/playbook/agent-skills?present=1) で Skill の仕組み・召喚され方を確認できます。

まず [`theomonfort/skills`](https://github.com/theomonfort/skills) からハンズオン用の 2 つの Skill をインストールします。方法 B では、スライド作成、プロトタイプ、設計の質問に使う 3 つも追加します。

### 5.1 — ハンズオン用の Skill をインストール

インストールするのは次の 2 つの Skill です：

- **github-issues** — bug report / feature request / task など複数のテンプレを持ち、ラベル・優先度・依存関係まで含めた構造化された Issue を書ける。後ほど Issue 作成で使います。
- **hands-on-helper** — このハンズオン参加者向けに、リポジトリ・手順書・Playbook の案内とトラブル解消をしてくれるガイド役。

#### 方法 A: 装備所からまとめてコピー（推奨）

1. 新しいタブで [**装備所 (EQUIPMENT ROOM)**](https://theomonfort.github.io/theomonfort/skills/#skills) を開く
2. スコープ切替が **プロジェクト .github/**（左、デフォルト）になっていることを確認
3. **🎴 スキル** セクションで `github-issues` / `hands-on-helper` の 2 枚にチェックを入れる
4. 右上の **💾 選択 2 を コピー** ボタンを押す
5. Codespace の VS Code ターミナルに貼り付けて Enter

#### 方法 B: コマンドをコピーして制作向けの Skill も追加

ハンズオン用の 2 つに加えて、同じリポジトリから次の 3 つをインストールします：

| Skill | できること |
| --- | --- |
| [md-slides-creator](https://github.com/theomonfort/skills/blob/main/skills/md-slides-creator/SKILL.md) | 通読できる資料とスライドを兼ねた Markdown を作成 |
| [prototyper](https://github.com/theomonfort/skills/blob/main/skills/prototyper/SKILL.md) | 1 つの HTML プロトタイプで UI の 10 案を比較 |
| [grill-me](https://github.com/theomonfort/skills/blob/main/skills/grill-me/SKILL.md) | 実装前に質問を通じて計画や設計を検討 |

スライド作成 Skill の公開名は `creator-slide` ではなく **`md-slides-creator`** です。インストールや呼び出しにはこの名前を使います。

**COPY** を押し、ハンズオンのリポジトリ内のターミナルに貼り付けてください。以下は **GitHub Copilot** と **project** スコープを明示し、グローバル環境にはインストールしません：

```bash
gh skill install theomonfort/skills github-issues --agent github-copilot --scope project && \
gh skill install theomonfort/skills hands-on-helper --agent github-copilot --scope project && \
gh skill install theomonfort/skills md-slides-creator --agent github-copilot --scope project && \
gh skill install theomonfort/skills prototyper --agent github-copilot --scope project && \
gh skill install theomonfort/skills grill-me --agent github-copilot --scope project
```

方法 A でインストール先を聞かれた場合は、次のように選択します：

- **Agent**: **GitHub Copilot**（`github-copilot`）を選択
- **Scope**: `project`（プロジェクト = このリポジトリ専用にインストール）

`.agents/skills/` に `github-issues/` と `hands-on-helper/` が追加されます。方法 B では `md-slides-creator/`、`prototyper/`、`grill-me/` も追加されます。各 `SKILL.md` を開いて指示を確認してください。[GitHub CLI のインストール仕様](https://cli.github.com/manual/gh_skill_install) も参照できます。

先ほど作成した **Instructions** は `.github/` 配下、**MCP サーバー** の設定はルートの `.mcp.json` にあります。Skill は **オープンエコシステム標準** の `.agents/` 配下に配置されます（GitHub 専用なら `.github/skills/` も利用可能）。詳しくは [Harness Engineering / エコシステム対応表](/theomonfort/playbook/harness-engineering?present=1&slide=6) を参照してください。

<Aside type="negative">

**⚠️ 重要**: Skill をインストールした後は **Copilot Chat の新しいセッションを開いてください**（`+ New Chat`）。既存セッションには Skill が読み込まれず、後続ステップでうまく召喚されません。

**Copilot Chat のバージョンによっては Skill が読み込まれないことがあります。** その場合は、次の 3 つを順番に試してください：

1. **新しいセッションを開く**（`+ New Chat`）
2. **ウィンドウを再読み込み**（コマンドパレット → **Developer: Reload Window**）
3. それでも読み込まれない場合は、**Skill フォルダを `.github/skills/` 配下に移動**すると確実に認識されます（例：`.agents/skills/hands-on-helper/` → `.github/skills/hands-on-helper/`）。

</Aside>

### 5.2 — hands-on-helper を試す

新しい Copilot Chat セッションを開いて、`hands-on-helper` Skill が正しく装備されているか確かめましょう。チャットに以下を入力してください：

```
/hands-on-helper

Skill のインストールまで終わりました。次のステップは何ですか？
```

`hands-on-helper` が召喚され、次にやるべきステップ（**CODE: Copilot Chat**）への案内と、関連する Playbook ページのリンクを返してくれれば成功です。
