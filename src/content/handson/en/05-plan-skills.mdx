Start with two workshop Skills from [`theomonfort/skills`](https://github.com/theomonfort/skills). Option B also adds three Skills for slides, prototypes, and design questions.

### 5.1 — Install workshop Skills

The two Skills we'll install are:

- **github-issues** — ships multiple templates (bug report / feature request / task) and can write structured Issues complete with labels, priorities, and dependencies. You'll use it later for Issue creation.
- **hands-on-helper** — a guide that helps this workshop's participants navigate the repository, the instructions, and the Playbook, and troubleshoots issues along the way.

#### Option A: Copy from the equipment room (recommended)

1. Open the [**EQUIPMENT ROOM**](https://theomonfort.github.io/theomonfort/en/skills/#skills) in a new tab.
2. Confirm that the scope toggle is set to **Project .github/** (left, the default).
3. In the **🎴 Skills** section, check the two cards for `github-issues` and `hands-on-helper`.
4. Click the **💾 Copy 2 selected** button in the top right.
5. Paste into the Codespace's VS Code terminal and press Enter.

#### Option B: Copy the commands and add three creative Skills

This option installs the two workshop Skills plus these three from the same repository:

| Skill | What you can do |
| --- | --- |
| [md-slides-creator](https://github.com/theomonfort/skills/blob/main/skills/md-slides-creator/SKILL.md) | Create a Markdown reference document that also renders as slides |
| [prototyper](https://github.com/theomonfort/skills/blob/main/skills/prototyper/SKILL.md) | Compare 10 UI design options in one HTML prototype |
| [grill-me](https://github.com/theomonfort/skills/blob/main/skills/grill-me/SKILL.md) | Stress-test a plan through focused questions before implementing |

The slide-creator Skill is published as **`md-slides-creator`**, not `creator-slide`. Use that name when installing or invoking it.

Hit **COPY** and paste into the workshop repository's terminal. These commands explicitly select **GitHub Copilot** and **project** scope, not your global environment:

```bash
gh skill install theomonfort/skills github-issues --agent github-copilot --scope project && \
gh skill install theomonfort/skills hands-on-helper --agent github-copilot --scope project && \
gh skill install theomonfort/skills md-slides-creator --agent github-copilot --scope project && \
gh skill install theomonfort/skills prototyper --agent github-copilot --scope project && \
gh skill install theomonfort/skills grill-me --agent github-copilot --scope project
```

If you use Option A and the installer asks for a destination:

- **Agent**: pick **GitHub Copilot** (`github-copilot`).
- **Scope**: pick `project` (installs the Skill into this repository only).

Each Skill creates a directory under `.agents/skills/`: `github-issues/` and `hands-on-helper/`, plus `md-slides-creator/`, `prototyper/`, and `grill-me/` with Option B. Open each `SKILL.md` to review its instructions. See the [GitHub CLI installation reference](https://cli.github.com/manual/gh_skill_install).

The **Instructions** we set up earlier live under `.github/`, while the **MCP servers** are configured in root `.mcp.json`. Skills follow the **open-ecosystem convention** under `.agents/` (`.github/skills/` also works if you only target GitHub). See [Harness Engineering / Ecosystem map](/theomonfort/en/playbook/harness-engineering?present=1&slide=6) for the full layout.

<Aside type="negative">

**⚠️ Important**: After installing Skills, **open a new Copilot Chat session** (`+ New Chat`). Existing sessions won't load the new Skills, and they won't be summoned correctly in later steps.

**Depending on your Copilot Chat version, the Skill may not be loaded.** If that happens, try these three things in order:

1. **Open a new session** (`+ New Chat`).
2. **Reload the window** (Command Palette → **Developer: Reload Window**).
3. If it still isn't picked up, **move the skill folder under `.github/skills/`** and it will be recognized (e.g. `.agents/skills/hands-on-helper/` → `.github/skills/hands-on-helper/`).

</Aside>

### 5.2 — Try out hands-on-helper

Open a fresh Copilot Chat session and confirm that the `hands-on-helper` Skill is correctly equipped. Type the following into the chat:

```
/hands-on-helper

I just finished installing the Skills. What's the next step?
```

You're good to go if `hands-on-helper` is summoned and replies with the next step (**CODE: Copilot Chat**) and links to the relevant Playbook pages.
