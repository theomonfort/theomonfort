### 3.1 — Verify the GitHub MCP Server

The template already configures the GitHub MCP Server in **`.mcp.json` at the repository root**. You will add Context7 in section 3.2.

Open `.mcp.json` and confirm that the following configuration is present:

```json
{
  "mcpServers": {
    "github-mcp-server": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "tools": ["*"]
    }
  }
}
```

Open **Customizations → MCP Servers → Workspace** and confirm that `github-mcp-server` is listed with **`.mcp.json`** as its source. Click **Start** if shown. Review the endpoint and requested permissions before accepting any trust or sign-in prompts. Never commit credentials.

In **Customizations → Tools**, confirm that the `github-mcp-server` tools (Issues / PRs / code search, etc.) are available to the session.

⏱ About 1 minute

<Aside type="positive">

**Tip**: The GitHub MCP Server is officially provided by GitHub. It feels like running `gh` commands — Copilot can directly operate Issues / PRs / Actions / Code search.

</Aside>

### 3.2 — Add the Context7 MCP Server

**Context7** is an MCP Server that pulls **the latest official documentation** for libraries and frameworks into Copilot. Recommended when working with fast-moving frameworks like Astro / Tailwind / TypeScript.

1. Open **Customizations** and select **MCP Servers**
2. Click **+** in the **Workspace** group, not **User**
3. For the transport, select **HTTP (HTTP or Server-Sent Events)**
4. Paste `https://mcp.context7.com/mcp` as the URL
5. Enter **`context7`** as the **Server ID** so it is easy to identify in the tool list
6. If prompted for a destination, choose **Workspace**, saving to root **`.mcp.json`**, not a User / Global configuration
7. Review any trust or authentication prompts, then start the server if needed

After adding it, confirm that root `.mcp.json` contains **both** servers. Keep the existing GitHub entry:

```json
{
  "mcpServers": {
    "github-mcp-server": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "tools": ["*"]
    },
    "context7": {
      "type": "http",
      "url": "https://mcp.context7.com/mcp",
      "tools": ["*"]
    }
  }
}
```

In **Customizations → MCP Servers → Workspace**, both `github-mcp-server` and `context7` should show **`.mcp.json`** as their source. If `context7` shows **Start**, click it.

To verify it works, try the following in Copilot Chat:

```
Use Context7 MCP tools to summarize the latest documentation for Astro content collections. Cite the documentation returned by the tools. Do not change files.
```

Expand the tool call and confirm it belongs to `context7` and returned documentation without a connection error. A plausible answer alone does not verify the connection.

⏱ About 2 minutes

<Aside type="positive">

**Tip**: Adding the HTTP endpoint directly avoids downloading a local package with `npx`. Network access and any required authentication still apply.
From now on, just ask "What's the latest Astro API?" or "What's the new syntax in Tailwind v4?" and Copilot will pull the official docs via Context7. You no longer need to worry about training data cut-offs.

</Aside>
