### 12.1 — Bring the repositories and brief together

First, **save, commit and push your Codespaces work**, then review and merge your Test & Secure PRs. Open the Copilot App with access to your hands-on repository and continue from that updated, reviewed state, not a stale local `main`.

1. Use **+ beside Projects** to create a Project for this website.
2. Add these three repositories to the Project. Only your hands-on repository is an implementation target.
3. [Download the Word brief](/theomonfort/handson/copilot-app-project-brief.docx), then use **Library → Add → Add file…** to attach it.

The solar-system reference deliberately differs from our site: Sun + eight astronomy planets, navy/amber styling and a detail panel. Adapt its data and interactions to **SDLC categories, Playbook routes and the retro theme**, rather than copying the astronomy UI.

### 12.2 — Compare first, then approve a plan

Send this single prompt to the Project, replacing the repository name:

```text
Read the Word brief in Library and compare all three repositories.
Only <my hands-on repo> may change; the two irl-odyssey repos are read-only references.
Start from current main; inspect current features and tests.
Propose one plan and tests for adapting the solar system to our SDLC categories,
Playbook routes and retro theme, and integrating read-only Zettelkasten with bundled notes.
Preserve licenses, existing features and content.
Follow the brief's read-only configuration: no visitor editing, note-write requests or backend.
Wait for my approval, then implement both agreed integrations and tests on a dedicated branch
in my repo, reusing existing features without duplication.
Run relevant checks, show the reviewable diff and results, and stop task-owned browsers/servers.
```

Review the proposed plan and tests, then approve them in the conversation.

### 12.3 — Review the integrations

In **Overview** and the conversation, check that 3D destinations match your site's categories/routes and existing features still work. Confirm that graph exploration, search, note reading and links work without editing or note-write requests.

Review the target-only diff, test results and license notices before opening and merging the integration PR.

Continue to [Part 13: Operate](/theomonfort/en/handson/operate-agentic-workflow/). The advanced integrations are not prerequisites for that part.
